## 二、数字口径红线（违反即返工）

1. **正文数字以附录 D 为唯一权威**；同一指标全文只允许一个数字。改数字前先查 `numbers_audit.py` 顶部的指标表（`canon` 合法值 / `stale` 黑名单 / `kw` 宽松值）。
2. **黑名单值出现在正文即 ERROR**：845、1.4%、1.63%、51,785、25.9%、45.5%。宽松口径值（0.9%/4.9%/1.8%/3.08% 等）只允许出现在方法说明或对比表。
3. **不许改口径**。例如接住率有 16.3%（全部提问）与 26%/25.8%（学生高阶应答后）两个口径，是两个漏斗位置，不得互换或相加。
4. 新增数字**先登记进附录 D、再进正文**；改动后必须 diff 软指标明细，确认是真实改善而非拆东墙补西墙。
5. **核心构念效度先于外围变量（2026-09-21 教训）**：任何由**多类合并**而成的二分变量（如"接住"= 拓展深化 ∪ 追问推进），在用它建叙事之前**必须先拆开分别估效应**。本论文因此吃过亏：合并口径下 26% 与 +8.1pp 看着合理，拆开后追问 +10.86pp、拓展 **+0.02pp（p=0.976，效应为零）**，有效部分仅占 28.5%，整套叙事需要重写。判据：若两亚类效应差 >5pp 或一者 p>0.9，**禁止合并报数**。
   - **拆完要再拆一层（2026-09-21 study30 教训）**：追问推进被判定"有效"后，其内部仍异质——按文本分为 要理由 **+17.55pp**（p=2.5e−9）／反问设错 **−10.43pp**／延伸推进 **−7.40pp**，后续高阶率 52.84% vs 26.16% vs 27.22%。**一个"有效"类目里可能只有 1/3 真正有效**。凡样本量 ≥1,000 的关键行为类目，都应尝试子类分解。
   - **拆出来的"有效子类"必须再做因子设计，排除替代解释（2026-09-21 study31 教训）**：子类被判定有效后，要问"是这个语义有效，还是某个伴随特征有效"。study31 发现"简短索要理由"（≤40 字）68.15% 远高于"长段索理"36.21%，立刻面临替代解释"其实是少讲有效"。**必须用 2×2（语义 × 伴随特征）分离主效应与交互**：实测简短主效应 +6.03pp（p=0.10，n.s.）、索理主效应 +9.49pp（p=0.0066）、**交互 +25.08pp（p=3.9e−6）** → 替代解释被排除，结论成立。**只看一组的组内差（+31.94pp）远不如交互项有说服力**。
   - **构念重构后必须整条机制链重跑**，不能只换一个数字：率、分层、结构条件、延续效应、孵化、效标全部要按新口径重算（study30a/30b 即此作业）。重跑时每个结论都要给"旧值 → 新值"对照表。
   - **"有效"类目定位到具体行为后，还要定位到具体位置（2026-09-21 study34 教训）**：判定"简短索要理由"有效之后，不能停在"少讲"这种笼统表述。要把那句话**按关键标记切成两段**分别估效应，并做**双侧二分四格**（互不重叠）。结果两侧独立且强度不同（说完之后接着讲 −0.1278/50字 vs 问之前铺垫 −0.0812/50字，差 1.57 倍）→ 表述从"少讲+追问"精确到"**直接要理由、说完就停**"。**凡是"某行为有效"，都要追问有效的是它的哪一部分、哪一段。**
6. **效标分层红线（2026-09-20 起）**：`课堂综合评分` 是**三维度加权**，写"接住/某机制 → 质量更高"时必须标明是哪个维度，且**不得用综合评分单独充当"对学生有价值"的证据**。实测：接住率 ~ 关键行为 **+0.322**（p=6e−34）／~ 关键能力 **+0.043**（p=0.125，n.s.）／~ 情感 **+0.013**（n.s.）。主证据应取**学生侧过程指标**（延续效应、孵化效应、认知类别数）；综合评分降级为"与教师行为维度的一致性证据"，并在局限中承认效标含教师行为维度、存在同源风险。
   - **补强（study30）**：把追问率与拓展率**同时**入模预测关键行为分，两者均显著（β=+15.0 / **+17.9**，后者更大），而学生侧只有追问有效 → 准确表述不是"评分奖励错的"，而是**评分无法区分有效回应与无效回应**。这条必须写进 7.4 局限。
   - ⚠️ **实例层 vs 课层结论冲突时以实例层为准**：课层面拓展率对学生后续高阶产出也呈正效应（+10.84pp, p=0.023），与实例层的零效应矛盾，这是聚合偏倚（拓展率高的课整体质量高）。课层相关不等于个体效应。

## 三、numbers_audit.py 的已知解析陷阱（改稿时最易踩）

审计脚本用正则解析"（作者，年份）"，以下场景已加固，**修改脚本时勿回退**：

- **年份字母后缀**：`2026a/2026b` 必须能被识别，否则同期两篇被静默跳过 → 误报"引用缺失"。
- **并列年份分隔**：中文常用顿号（`2026a、2026b`），分隔符须含 `、`，否则整条引用漏识别。
- **姓氏介词前缀**：`van de Pol` / `von Neumann` 需先剔除 van/von/de/der/di/da/la/le/del/dos 再取姓氏；否则正文取到 `pol`、文献表取到 `van`，两侧不匹配。
- **非引用括号**：`（2022 年版）`、`（合计 1874 节…）` 会被年份正则诱惑，必须靠 `CITE_SUB` 全匹配 + `\s*$` 锚定静默跳过。
- **中文多作者顿号**：`曹一鸣、于国文` 的 `、` 必须在中文字符类内，否则判为死条目。
- **英文摘要拼音署名**：`Cao et al., 2022` 需经 `PINYIN_ALIAS` 映回中文名，否则误报缺失+死条目。
- **变音符号**：`Güner`/`Bozkuş` 需 `LAT` 字符类覆盖 Latin-1 补充区与 Latin Extended-A。

**自验规则**：任何接受文件路径参数的核查脚本，必须先用两个不同输入跑一遍、比对输出字节数，确认真的读了不同文件再采信结论（历史上曾因硬编码路径导致多轮结论全部基于同一张旧表）。

## 五、图片与格式规范（v4.0 起）

**插图约定**：正文写 `![图 X-Y  图题](../images/figX_Y_xxx.png)`（独立成行）。`md2docx_v3.py` 行首匹配 `![图题](路径)` → 插入居中图片（宽 14cm）+ 黑体 10.5pt 居中图题；相对路径按**合并稿所在目录**解析，故图片放 `01_论文/images/`、路径写 `../images/…`。

- **图内不要自带标题**：图题由正文统一给出，图内再写标题会重复。
- **图号按正文出现顺序**，且图号前缀必须与所在章一致（放在 4.4 节的图就该叫图 4-x，不能因为源清单里叫"图 5-3"就跨章编号）。
- 绘图脚本存 `.tmp/`，用实验 venv 的 matplotlib；中文字体用 `Heiti TC`（该机可用字体：Heiti TC / Songti SC / STHeiti / Hiragino Sans GB / Arial Unicode MS，**无** PingFang SC 与 SimHei）。上标减号等罕用字形会缺字，改用 mathtext（`r"$\rho=...,\ p=3.6\times10^{-27}$"`）。
- **复用现成图前先核对图内数字与正文是否一致**（历史上出现过图内写 R²=0.516、正文写 0.512）。不一致就按数据源重绘，或加注说明。

**引号规范**：中文正文一律用弯引号 `“ ”`。若发现混用（ASCII 直引号 `"` 与弯引号并存），按"**出现顺序交替赋值**"批量统一——先确认每个文件引号总数为偶数（奇数则跳过并报告），再依次赋 `“ ”`。替换前排除代码块与行内代码中的引号；**英文所有格单引号（`students'`、`O'Connor`、`Cohen's`、`Cramér's`）必须保留不动**。校验三招：无残留直双引号、无空引号对 `“”`、**行内引号不平衡行数 = 0**。

**交叉引用终扫**：用 `xref_check.py`（纯标准库，与 `numbers_audit.py` 并列）。它重建四类锚点（节号 61 个 / 表号 / 图号 / 章号）并反向校验全文「见 X.Y」「X.Y 节」「表 X-Y」「图 X-Y」「第 N 章」共 160+ 处引用，另校验图片文件 `os.path.exists`。**要求五项全 0 失效**。

**验收线**（卡 4 起）：`无编号表 = 0`、`图引用 > 0`、`ERROR 0`、`引用缺失 0`、`死条目 0`、`交叉引用失效 0`。

### 课堂结构变量（study28 用，从话语级重算）

话语级 `output_stage0/turns_clean.parquet`（402,537 行；列：`role`、`n_chars`、`form1`、`form2`、`func1`、`func2`、`lesson_id`）：
`form1 ∈ {管理,陈述,提问,回答,...}` → **教师讲解量代理 = 教师话语中 form1='陈述' 的轮次/字数**；
学生认知覆盖广度 = 课内学生 `func2` 去重数。**读 parquet 必须用 default 环境（fastparquet）**。

> ⚠️ **占比口径 vs 绝对量口径**：`密度 = 提问实例数 / 总轮次`、`学生轮次占比 = 学生轮次 / 总轮次` 共享分母，与学生话语量机械相关，易得出反向结论。**报告代价类结论时以绝对量为准**（study28 Q3 两口径结论相反）。

### 实例层 ↔ 话语级精确对齐（study29 打通，2026-09-21）

`study15_q_instances.csv` 的 34,621 条 **≡** `turns_clean.parquet` 中 `role=教师 & form1=提问` 的轮次（1997 课逐一核对完全相等，r=1.0）。对齐后可给每个语义编码实例配上真实话语属性：

```python
t = t.sort_values(["lesson_id"], kind="stable").reset_index(drop=True)
t["seq"] = t.groupby("lesson_id").cumcount()          # 课内全局序号
tq = t[(t.role == "教师") & (t.form1 == "提问")].copy()
tq["_ord"] = tq.groupby("lesson_id").cumcount()        # 与 study15 的 _ord 一一对应
d = q.merge(tq[["lesson_id","_ord","seq","n_chars"]], on=["lesson_id","_ord"], how="inner")
# 片段 = [本次提问 seq, 下次提问 seq)：区间内教师非提问话语=反馈，学生话语=回答
```
解锁的分析：反馈**剂量**（n_chars）、反馈**形态**（form1 是否陈述/回主线）、片段内学生话语量、后续教师行为。参考 `study29_dual_task.py` 的 `agg_between()`。

- 课层接住率的**测量信度仅 0.430**（观测方差 0.01177 vs 二项噪声 0.00670）→ 教师层估计是**下界**；且不能用一两节课评价教师（单课 SE≈±8pp）。**但不要把噪声从课层单侧剥离后重算占比**（会虚增上层），那是误导性的。
- 密度→接住（教师固定效应）β=−0.4855（p=0.0005）。

**新口径重跑基准（study30，2026-09-21）**——"接住"拆分后三类因变量并行：

| 因变量 | 全提问率 | 高阶应答率 | 教师层(多课子集) | 同师不同课 | 同师成对 r |
|---|---|---|---|---|---|
| 追问推进（有效） | 4.37% | **7.36%** | 12.2% | 71.7% | **0.302** |
| 拓展深化（无效） | 11.92% | 18.44% | 7.9% | 83.9% | 0.140 |
| 旧接住（合计） | 16.29% | 25.81% | 14.5% | 76.8% | 0.237 |

- ⚠️ **踩过的坑**：三层分解若用未筛提问数的全量课（1,180 课 / 1,002 身份，大量单课组），教师层 ICC 会被稀释到 5~18%。**必须先筛 `n_q≥10`，再取多课身份子集**（311 课 / 133 身份）才能与 study27 对齐。
- 课层两类率几乎正交（r=0.040）→ 是两个独立行为，不是同一维度两端。
- 信度：旧接住 0.572 / 追问 0.498 / 拓展 0.512；单课 SE ±5.8~10.5pp。

## 八、结构性调整（内容归位 + 编号级联）作业法

> v4.1 结构批（研究问题两问→三问、第四/五章内容归位）的作业方法。适用于任何"章节内容搬家"型改稿。

1. **先列映射表，再动一个字符**。把"原位置 → 新位置"写成三列表（节号 / 图表号 / 章标题各一张），人工核对无歧义后再执行。映射表本身就是最终要写进附录 D 变更登记的内容。
2. **搬内容用整章重写而非程序化切割**：章节同名的 md 文件不重命名（`merge_v3.py` 的 `ORDER` 依赖文件名，章标题取自文件内 H1）。重写时以原文为蓝本逐段搬运，避免正则切割把表格/图注切坏。
3. **图号按"出现顺序 + 前缀随所在章"重排，文件同步改名**：图表编号会随内容移动跨章，必须重编。图片文件名与图号一致（`fig5_1_shap.png` ↔ 图 5-1），改图号就改文件名。
4. **变更登记表的旧编号必须豁免引用校验**：附录 D 的"节号对照表 / 图表重编号表"里写的就是旧编号（如"原 4.5 → 新 4.3"），它们必然被 `xref_check.py` 判为失效。`xref_check.py` 用 `EXEMPT_SEC_MARKS = ("D.8", "D.9")` 按小节标题整段豁免，并把豁免数单独打印（不参与判定）——**不要为了让校验变绿而删掉登记表**。
5. **连带改写不容漏**：内容搬家后必查四处——① 各章开篇"本章回答研究问题几"；② 各章小结的指向句；③ 方法章（第三章）的流程分节是否仍对应新结构；④ 结论章（第七章）每条结论末尾的"见 X.Y，表 X-Y"。
6. **收尾三连**：`merge_v3.py` → `numbers_audit.py`（self-test + 主审计）→ `xref_check.py`（self-test + 主校验）→ `md2docx_v3.py`，再核 docx 结构（段落/表格/`inline_shapes`）与逐章字数占比。

## 八之二、全量人工语义编码的作业法（study31，可复用）

对 1,000~2,000 条话语做"人工（语义）编码"验证自动分类时的标准流程：

1. **先摸底**：看条数、文本长度分布、总字数（study31：1512 条 / 中位 63 字 / 共 12.2 万字），据此定批次大小（每批 110~150 条、约 1 万字最舒服）。
2. **写 dump 脚本按索引区间导出**（`study31a_dump_text.py START END`），输出格式 `序号|标签列|原文`，便于逐行读。
3. **批次 1 做开放编码并定框架**：先读第一批，归纳真实类型，再冻结编码表（含"不可判"兜底类），后续批次沿用；**不要中途改类目定义**。
4. **每批编码落盘为独立 part 文件**（`codes_pNN.txt`），合并脚本必须 `assert len(code)==len(data)` 且 `idx` 连续，防止漏编或错位。
5. **双维度优于一维度**：主类型（互斥）+ 效度标记（如"是否真的把话轮交给学生"）。效度标记能直接量化编码噪声（study31 中 18.8% 是附和式/自答，4.1% 其实在讲授）。
6. **验证的核心不是重算效应，而是三件事**：① 自动分类的类别**边界**是否吻合（study31 中"反问设错"不吻合即应弃用）；② 关键类的**率**能否被独立编码复现（要理由 52.84% → 54.22%）；③ 规模占比是否一致。
7. **发现组内异质后必须上因子设计**（见红线 5 第三条），并做三重稳健性：课内配对（同单位内比较，排除组间异质性）、切点/阈值敏感性、集中度（剔除高频单位后重算）。
8. **诚实交代**：单一编码者无 κ，必须在报告与论文局限中写明，并说明编码表已落盘可供第二编码者复核。

### 补充（study44 复查短索理 977 条所得，2026-09-24）

9. **编码时必须对结果盲**。dump 脚本只输出待编码文本，**绝不输出产出标签**（引出没引出说理、高阶与否）；产出在编码全部完成后再 join。否则会不自觉地"看着答案编码"，把高产区判得更"像索理"。study44 的 `study44a_dump.py` 就刻意只打 `#序号|原文`。
10. **编码序位 ≠ 原表行号**。被编码的往往是筛选后的子集（study44 是 `rs==1` 的 977 条），它们在原表里是**散落的行**。join 时必须 `_idx = df.index[df.mask]` 再 `dict(zip(_idx, codes))`，**不能**用 `range(len(codes))` 直接当行号——这个错会让全部结论整体错乱，而且**主类效应会出现假负号**（study44 首轮因此算出"追问为什么 −5.5pp"）。
11. **产出率必须报"有应答"分母**。提问级产出率里 39.5% 是 `run=0`（见红线 11.20），若把无应答提问算进分母，主类效应会被"哪类更容易没人答"污染。study44 主口径一律限定 `run>=1`，并在报告里注明与 study42 全样本口径的量级不可直接比较。
12. **人工编码的价值常在"推翻正则口径"**：study44 查出正则判为"短索理"的 977 条里 **15.7% 根本不是索理**（89 条在索答案/索结论、64 条是无内容承载的泛要求），且这批杂项对产出**完全无效应**（−0.7pp, p=0.87）。清洗后效应不是缩小而是**变大**（+24.5pp → +28.4pp）。**结论**：凡结论建立在正则/关键词类目上，人工复核后必须重算效应，不要假定"清洗只会缩小效应"。

## 十、多层分解的估计器纪律与法证流程

> 2026-09-20 用六轮独立法证推翻了正文沿用的一个核心数字，教训必须固化。

### 10.1 标准 ICC(1) 矩估计（唯一正确写法）

```python
g = df.groupby(groupcol)[valcol]
k = g.size(); gm = g.mean(); grand = df[valcol].mean()
SSB = (k * (gm - grand) ** 2).sum()                                    # 组均值的加权离散
SSW = df.groupby(groupcol)[valcol].apply(lambda x: ((x - x.mean())**2).sum()).sum()
MSB, MSW = SSB / (len(k) - 1), SSW / (len(df) - len(k))                # 分母：G-1 与 N-G
k0 = (len(df) - (k ** 2).sum() / len(df)) / (len(k) - 1)
ICC = (MSB - MSW) / (MSB + (k0 - 1) * MSW)
```

**两个致命写法**（study25_uptake_mechanism.py 都犯了）：
1. `ss_between` 的分母写成 `(N-1)` 而不是 `(G-1)` —— 数值被缩小 `(N-1)/(G-1)` 倍；
2. `ss_within` 直接用 **组内方差**（课层面），却与组均值的离散（另一层级）相加。

两者一除，得到的是 ≈`1/(1+k̄)` 的常数，**与真实组间信号基本无关**。

### 10.2 三重探针：任何组内相关都必须过三关

| 探针 | 做法 | 合格标准 |
|---|---|---|
| ① 实测 | 标准矩估计 | —— |
| ② 打乱法零假设 | 打乱目标变量、保持组结构，跑 N≥300 次 | 实测值必须**超出**零假设 95% 区间 |
| ③ 成对相关 | 同组两两观测的相关 | 与 ICC 同量级（两者同族） |

### 10.3 口径自洽：删单例组会抬高 ICC

- 删掉"只有 1 个观测"的组，ICC 会**系统性上升**（单例组本是纯噪声，起到稀释作用）。
- 实测：同一学校层，大样本 −0.001 → 多课子集 0.088（**8 倍差**）。
- **纪律**：每层 ICC 必须标注估计样本；不同层的样本不同时，**报"两个独立估计 + 残差"，不要拼成"三层方差分解"**（那暗示同一模型）。
- 打乱法可以救：多课子集上学校层 0.088 落在零假设内（噪声），教师层 0.232 超出（真实）——**同子集同估计器的对照，比跨样本比数字有力得多**。

### 10.4 窗口敏感性：任何"事件后 n 轮"的指标都要扫窗口

- 同一现象换窗口定义，效应量可以变 1.6 倍。
- 实例：延续效应在"3 话语轮次"（教师发言也计数）下 +11.9pp，"3 学生轮次"下 +8.1pp，"5 学生轮次"下 +7.3pp。
- **纪律**：主报保守口径 + 附录登记敏感性区间；**7 个窗口里 4 个不显著的对照（如"接住 vs 无反馈"）不要进正文**，那是被最有利口径救活的。
- 陷阱：`study15_q_instances.csv` 的 `high2` 是**预定义列**（窗口 = 反馈后 3 个话语轮次，教师发言也计数）。任何做"延续效应"的脚本**都要用同一列**，否则会出现两套口径。

### 10.5 测量信度：比例型课层指标的方差里含二项噪声

```python
noise = (p * (1 - p) / n_q).mean()      # 二项抽样噪声
信度  = 1 - noise / MSW                 # 课层指标的信度
```
课层接住率信度仅 **0.430**。含义：① 上层的 ICC 被噪声稀释，属**下界**；② 不能按单节课评价教师。
⚠️ **不要**把噪声从课层单侧剥离后重算占比（会虚增上层），那是误导性的。

### 10.6 法证脚本（`.tmp/icc_forensics*.py`，六轮，零 scipy 依赖）

| 脚本 | 用途 |
|---|---|
| 1 | 伪影定罪（打乱法 + 注入检验 + 成对相关） |
| 2 | 对称检验（学校层 vs 教师层同估计器）；修正的注入检验 |
| 3 | 支点数字核验（成对相关矩阵）、Δr 的 bootstrap、时间趋势 |
| 4 | jackknife CI、测量误差校正（信度） |
| 5 | 窗口敏感性扫描 + 与预定义列逐条核对 |
| 6 | 伪影链条闭合、口径自洽表、多课子集打乱法 |

**注意**：ICC 的 cluster bootstrap（按组有放回重抽）会产生**重复行**，组内被人为注入一致性 → ICC 被抬高，得到"CI 下界 > 点估计"的自相矛盾结果。**改用 jackknife 或解析法**；成对相关的 Fisher-z CI 是干净的备选。

## 十一、方法学红线（study37 审计所得，2026-09-21）

### 11.1 加性切分禁止做"哪一侧更重要"的比较
若某设计里 `X = A + B` 且 A、B 由同一总量切开（如同一句话在某个标记处切成两段），则
**"A 侧还是 B 侧更重要"在数学上不可识别**——它只是总长的重新参数化。
- **报警信号（任一命中即停手）**：
  1. `A + B − X` 的残差恒为 0（恒等式）；
  2. 分格后关键两格在 X 上**没有重叠区间**（如 ①X≤25 vs ④X≥31）；
  3. `R²(y~X)` 与 `R²(y~A+B)` 几乎相同；
  4. 把 A、B、X 同时入模时 SE 爆炸（p≈1）。
- **正确做法**：
  - **总量匹配下的对比**——只在 X 分布重叠的两格之间做 1:1 最近邻匹配（卡钳取 X 的 5~10%），匹配后必须先报"匹配后 X 无差异"（p>0.5）；
  - **固定总量后的结构变量**——把 A 换成占比 `A/X`，在 X 分层内做剂量-反应（Mantel-Haenszel 加权合并 + 含 X 的回归）；
  - 若两者都做不出效应，就老老实实承认：**只有总长效应，没有位置效应**。

### 11.2 窗口类分析的三条口径纪律
1. **前后测窗口必须等长**。不等长＝双向放大增益（后测越来越容易命中，前测越来越难）。旧版前 4 轮/后 6 轮曾把效应量抬高约 5pp。
2. **前后测必须同口径去噪**。前测未去噪、后测去噪 ＝ 组间不对称偏差（实测使长组前测被多污染 3.3pp、短组仅 0.8pp，又拉开差距约 2.6pp）。
3. **窗口首条话语要单独看待**：它常是**切分碎片或提问回声**，不承载目标行为。效应落在"第 2 条起"是常态，**不要**把首条的低值直接解释成"学生没被激发"。

### 11.3 判断"这是效应还是操作检查"
把原点从「触发事件本身」移到「该轮交互结束之后」，重算同一指标。
- **效应还在** → 真实延续；
- **效应消失**（如 +8.6pp → +2.8pp 且 CI 含 0）→ **它是操作检查**，即"做了这件事，当然会立刻得到那个反馈"，不能当作因果关系写入。
- 辅助信号：等暴露口径（只看等量的首条话语）会让效应腰斩；把原点后移会使"前测"变得不平衡（因为把交互本身移进了前测）。

### 11.4 用文本定位做锚点前，必须先验证"待定位文本确实是原文"
**教训（study37 一次真实误报）**：用一批短追问文本去话语表里做子串匹配，得到"99.7% 的提问不在预期位置、错位 +2 轮"，一度判定为全局数据对齐缺陷。
**实际是匹配方法本身失效**——那批文本是**改写/抽取**文本，不是任何一条话语的原文，于是到处误命中。
- **验证办法**：取一批**确定是原文**的文本（如另一份带原文的产物），用**完全相同的代码路径**跑一遍，看命中率是否接近 100%。
- 实测对照：改写文本 1512 条里只有 **9 条**能命中；原文文本 5639 条里 **5639 条**命中且位置吻合 97.7%。
- **在得出"数据源有问题"这类结论前，先用已知正确答案的样本验证自己的检测器。** 否则会把正确的数据"修坏"。

### 11.5 pandas 保留属性撞名清单（列名撞上就静默出错）
`T, tail, sub, add, mul, div, pow, abs, all, any, min, max, sum, mean, median, std, var, count, size, shape, ndim, empty, index, columns, values, keys, first, last, pop, mask, where, dot, mode, rank, shift, diff, drop, filter, apply, map, join, merge, at, iat, loc, iloc, plot, hist, boxplot, describe, cumsum, cumprod, swaplevel, squeeze, rename, replace, round, clip, iterrows, items`
- **凡是可能撞名的列，一律写 `df["col"]`**。已踩坑：`df.T`（study33b）、`df.tail`（study34c）、`df.sub`（study37a）。
- 静默症状：产出空表 / `AttributeError` / 拿到方法对象参与运算而报 `TypeError: unsupported operand type(s) for -: 'method' and 'int'`。

### 11.6 Py3 字符串里写中文标点时的引号陷阱
在 `print("...")` 里嵌入 **ASCII 直引号**会提前终止字符串（报 `SyntaxError: invalid syntax. Perhaps you forgot a comma?`）。
- **中文内容一律用中文引号**「」“”或直接去掉引号；**阿拉伯数字/英文用 ASCII 引号**。
- 同理：**不要在全角环境里用 U+2212（−）当减号**，它是合法字符但会被当成标识符字符，在列名/表达式中报 `invalid character`。用 ASCII `-`。

### 11.7 由总量定义的指标不能当机制证据（构造性陷阱）

若某指标在定义上就是两个量的比值，而自变量恰好是其中一个量的驱动因素，则该指标的变化是**机械的**，没有识别力。

- **已踩坑**：用"窗口内学生话轮占比 = 学生字数 /(学生字数+教师字数)"去证明"短提问把话轮让渡给学生"。短提问→教师字数少→占比必然上升，这是**恒等式**，不是发现。实测 A短 0.305 vs A长 0.151（p=2.6e−21）看着极显著，但不可用。
- **判别办法**：问一句"如果我完全不看数据，只根据自变量能否算出这个指标的必然方向？"若能，就是构造性的。
- **同族陷阱**：`A+B ≡ X` 的加性切分（见 11.1）；`比率型终点` 与 `暴露量` 未匹配（见 11.2）；`时长/字数` 作中介时与处理变量共线。
- **替代做法**：改用**不由总量定义**的独立量。本例改报"学生话语字数（绝对值）+ 条数 + 说理密度"三件套，方向一致且各自独立。

### 11.8 共时关联里的内生性：不要把"同时发生"读成"造成"

在同一个话语窗口内构造的"前因—后果"变量，方向往往不可识别。判据：**后果变量为真时，前因变量在机制上是否必然出现？**

- **已踩坑**：回归 `下一条是否说理 ~ 中间教师话语条数`（限定前一条说理），得 β=−0.185~−0.279、p<1e−30，看似"教师一介入就说理中断"。但**学生不连续说话时，教师当然要说话**——这是同义反复。该系数**不可作因果解释**。
- **可用做法**：
  - 换成正向实验式对比：把一个**外生触发的处理**（如"教师是否使用了短索理"这类具体行为）与结局对照，而不是用"话语条数"这种由对话结构决定的量；
  - 或明确降级为"描述性关联"，在正文里写清不可识别。
- **自查**：这个 x 会不会因为 y 的变化而变化？会 → 不能作因果。

### 11.9 检验"行为聚集性"：置换零分布 + 按间隔分层排除切分伪影

要论证某行为"成串发生"（不是均匀散布），三步走：

1. **转移概率**：课内 `P(行为 | 前一条也发生) − P(行为 | 前一条不发生)`。必须**课内**算，否则课间异质性会伪造聚集。
2. **置换零分布**：课内随机打乱该行为标签，重算转移差，得到零分布。用 obs 均值相对零分布的 z 检验。实测参照：z=+22.2，p=4.9e−109（2,216 课）。
3. **按间隔分层（关键，排除切分伪影）**：话语切分常把一段话切成两条并**赋予相同属性**，会在"相邻"格伪造出极强聚集。
   - 分层报告 `间隔=0 / 1 / 2 / 3-4 / 5-8 / 9+` 各格的转移差。
   - **判据**：若聚集只存在于间隔 0–1，是切分伪影；若间隔 ≥2 仍有聚集，是真实时间结构。
   - 实测参照：0 → +0.288（含伪影）｜1 → +0.149｜2 → +0.106｜3-4 → +0.085｜5-8 → +0.056｜9+ → +0.029（衰减但从不消失，**半衰期约 2–3 条话语**）。
   - 抽原文人工确认间隔 0 的案例是否真是同一段被切开。
4. **归因限制**：无学生 ID 时，无法区分"同一学生连续说"与"不同学生接力"。只能写"课上是否持续发生该思维"，**不能写"某个学生被点燃"**。

### 11.10 置换零分布的聚合值通常不是 0——必须与零分布比，不能与 0 比

在**课内**做标签置换（保持每课行为总数不变、保留课间异质性）时，聚合到全样本的统计量常**偏离 0**，这不是 bug：

- **成因（组分效应 / Simpson）**：若统计量是"两组率的差"（如 `Δ = P(b|前b) − P(b|前非b)`），则**行为率高的课对分子贡献大、行为率低的课对分母贡献大**。即使每节课内部完全随机，课间基线率的差异也会让聚合 Δ 系统性为正。
- **实测**：五种学生行为在课内随机打乱后，聚合 Δ 零分布中心落在 **+0.027 ~ +0.123**，而不是 0。
- **纪律**：
  1. 只能报 **z = (观测 − 零分布均值) / 零分布标准差**，以及**净超额 = 观测 − 零分布均值**；
  2. **禁止**把 `观测 / 零分布` 当"超额倍数"——不同行为的零分布中心不同，比值排序会完全错。本论文首版曾因此得出"说理 2.7× > 长话语 1.7×"的错误排序，改为净超额后两者接近（+0.093 vs +0.085）。
  3. 零分布必须报告均值与标准差，不能只报 p。

### 11.11 事件串（run / 生存）分析的作业法

分析"某行为是否成串、能持续多久"（如说理串）的标准流程：

1. **先定连续性阈值 TH 并做敏感性**。`相邻两次行为之间隔 ≤ TH 条话语算同一串`，TH 取 0 / 1 / 3 三口径。TH=0 只含"紧邻"，**易被话语切分污染**，须单列。
2. **切分伪影的四条排除**（缺一不可）：
   - 相邻行为对中"一条是另一条子串"的比例（实测 1.66%，可接受）；
   - 相邻行为对的**字数中位**（若是碎片会显著偏短；实测 40/41 字，属完整话轮）；
   - **剔除短话语后重算**（剔 <12 字 / <20 字，实测 z 从 +27 降到 +12，仍显著）；
   - 再剔除**提问回声**（学生话语 ⊆ 教师话语）。
3. **零分布用课内置换**（保持每课行为条数），不要用跨课随机——那会把课间异质性也算成聚集。
4. **尾部比均值有说服力**：报告完整长度分布并与**独立几何基线**对比。若 p 为单条行为率，独立时 `P(L=k) = p^(k-1)·(1-p)`。实测均值只从 1.093 抬到 1.215，但 P(L=3) 是基线 4.5×、P(L≥6) 是 **220×** ——只说均值会把最强的证据丢掉。
5. **危険函数（衰减曲线）**：`P(下一条也是该行为 | 距上次该行为 k 条)` 逐 k 报告，并配 logit + 聚类稳健 SE、以及**课内去均值 LPM** 复核（排除课间差异）。注意"距离"= 两条学生话语之间的**教师话语条数**，含义要写清。
6. **"什么能延长它"要做阴性对照**：把所有候选因子（教师行为、课层属性、时段位置）逐个估，**阴性结果与阳性同等重要**。实测：索理追问触发的串与其它一样长（p=0.686）——**"能点火"不等于"能助燃"**，这两件事必须分开报。
7. **对照"该行为是否独有"**：至少再取 3~4 个同类行为（本例：长话语 / 观点表达 / 提问 / 否定）算同一指标。若都成串，则"成串"是话语互动通性，**不能单独当认知证据**；此时须用**联合模型**剥离伴随特征（控制前一条的字数、是否长话语、是否含观点），看目标行为的前驱是否还有独立系数。
8. **恒等式陷阱**：任何"跨单位边界"的子集，若其定义本身蕴含长度 ≥2（如"跨越提问边界的串"必然至少两条），则其 P(长度≥2)=1 是恒等式，**不能当证据**。

### 11.12 pandas 读 parquet 与 itertuples 的两个小坑

- `for r in df.itertuples(): r["列名"]` 会报 `TypeError: tuple indices must be integers`。改用 `r.列名`（中文列名不适用）或 `for a, b in zip(df["甲"], df["乙"])`。
- 大样本**纯 Python 循环 + 置换**（如 2,000 课 × 2,000 次重抽）会挂死。先把统计量**向量化**（用 `np.flatnonzero` + 断点切分替代逐元素循环），再考虑减少重抽次数（600 轮已足够稳定）。

### 11.13 正态尾概率助手必须写明"单侧还是双侧"（study40 踩坑，2026-09-21）

自实现的 `norm_sf(z)` 若写成 `0.5 * scipy.special.erfc(|z|/√2)`，返回的是**单侧** p（= Φ(−|z|)）。标准写法是：

```python
def norm_sf(z):                       # ← 双侧尾概率，调用处不要再乘 2
    z = np.abs(np.asarray(z, dtype=float))
    return scipy.special.erfc(z / np.sqrt(2))
```

- **踩坑经过**：study40b 用了 `2*norm_sf(...)`（对的），但 study40c/d/e 直接引用 `norm_sf(...)` → **全部 p 值偏小一半**。修正后重跑，主结论存活，但两处（课层加控制后 β、寒蝉效应）从"显著"退为"不显著"。
- **教训**：不同脚本各拷一份助手函数时，**定义与调用处的乘数约定必须同步**。凡自实现统计助手，在 docstring 里写死"返回双侧 p"，且调用处**永远不要再乘 2**。
- 校验方法：`norm_sf(1.96)` 应 ≈ 0.05（双侧），若得 0.025 就是单侧。

### 11.14 事件窗口的"定义内生"陷阱（study40）

把"某行为之后到下一次 X 为止"当分析窗口时，若**该行为本身就是 X 的一种**，窗口长度会被人为压缩，对比结果是定义造出来的。

- **实例**：算"追问花掉多少话轮"时用"到下一次提问为止"做窗口——但`fb_detail=="换题提问"`（过站的一种）的**下一条就是提问**，窗口天然只剩学生块（3.3 话轮 vs 追问 8.7）。这是假对比。
- **正确做法**：改用**固定长度窗口**（如"从学生应答块结束起，取后续 6 条话语"），两组窗口等长才可比。

### 11.15 序列分组（题链 chain）的断链规则不能只看 pad 字面值（study40）

按 `pad == "连环提问"` 续链是**错的**：追问（`form1=反馈, form2=深化/拓展`）之后的下一条提问，其 `pad` 是 `"接住深化"` 而不是 `"连环提问"` → 链内计数恒为 0（而且不报错，静默出错）。

**正确断链判据**（基于上一条教师话语的原始 form1/form2）：

```python
brk = (prev_teacher is None or prev_teacher[0] == "管理"
       or prev_teacher[1] in ("发布指令", "学习指引", "环节转换"))
```

**自检**：任何"组内累计"变量（chain 内第几次、链内已追问几次）跑完必须看分布——**若某个取值占了 100%，一定是逻辑写错，不是数据如此**。

### 11.16 `pd.cut` 默认丢掉左端点（study40）

`pd.cut(x, [0,.25,.5,.75,1.0])` 的区间是右闭左开，**`x==0` 的记录全部落在区间外被丢弃**（本研究里 = 每节课的第一个提问，一次丢掉 1,997 条，且不报错）。

- 凡是分箱边界可能取到最小值（relpos、进度、序号等含 0 的量），必须 `include_lowest=True`。
- **自检**：分箱后各组 n 之和应等于原始样本量；不等就是丢了边界。

### 11.17 下游脚本不得复用已判错位的数据源（study39b 审计教训）

39b 的触发源标注复用了 `study15_q_instances.csv`，而主链（40a）已判定该表错位——**主链修了，下游没跟着修**。后果：触发源分布整体漂移（追问触发 134→225、非提问 7,566→6,233），点估计差一倍（+2.0pp→+4.3pp）。

- **规则**：任何一个数据源被判定有问题并重算后，必须 `grep` 全库找还有谁在读它，逐个改口。
- **同批审计的另外两件**：① 注释与代码不符（40d 窗口注释写"跳过反馈"实际含反馈）→ 别信注释，跑口径敏感性定对错；② 回声（学生复读教师提问）疑虑要**测**而不是猜——回声条含说理词仅 1.1%，剔回声 P(≥2)=0.1567 vs 0.1563，疑虑排除。审计产出三行结论：**通过 / 通过 / 已修正并更新报告数字**。

### 11.18 回归里必须加截距（study42 踩坑，2026-09-24）

自建"分块设计矩阵"（blocks 列表 → `np.column_stack`）时，**第一块必须是常数 1**。漏掉截距后 IRLS 仍会收敛、不报错，但**所有哑元系数都变成"相对概率 0"的绝对水平**，符号会整体错乱（study42 首轮出现"探究式 β=−0.58"这一与原始交叉表完全矛盾的负号）。

- **自检**：回归跑完先和原始交叉表对一遍符号；若某哑元的系数符号与分组均值差相反，99% 是漏了截距或参照类设置错。
- 课内固定效应（LPM + 去均值）**不需要**截距（去均值后截距为 0），两者别混。

### 11.19 多分类哑元的"参照系陷阱"（study42）

同一批数据里，**多分类变量（题型、环节）的系数高度依赖省略的参照类**。study42 的课内 FE 中，题型以"其他/程序式"为参照，得到"确认式 +2.1pp（显著为正）"；但换成"**该题型 vs 该课其余提问**"的组内差，确认式是 **−2.7pp（显著为负）**——因为程序式本身最差（−2.4pp）。

- **定稿口径建议**：涉及多分类的效应汇报**一律用"各类 vs 该组其余"的组内差**（逐课/逐层内比较后取均值），并在正文写明"效应为相对于该课其余提问的差值"。
- 必须给读者交代参照类是什么，否则"确认式显著为正"会被读成"确认式提问好"。

### 11.20 提问级产出率的分母口径：run=0 不是"学生没回答"（study42）

事件表里 **39.5% 的提问 `run=0`**（提问之后到下一条教师话语之间没有学生话语）。抽查原文发现它混了三种情况：教师自问自答、转写把学生话标注成教师（study33 已证长索理后有 21.1% 角色错标）、以及真的无人应答。**不能写成"学生没回答"**。

- 涉及"提问产出率"的结论，**必须同时报两种分母**：①全样本（含 run=0）；②`run>=1`（有学生应答）。
- study42/41b 实测：两种口径下结论方向一致，条件口径下效应**更大**（41b 短索理 vs 非索理：A 组 +27.2pp→**+36.3pp**；B 组 +16.2pp→**+22.6pp**）。
- 原始产出率对比：全部提问高阶 15.3% / 说理 5.5%；**仅有应答** 25.4% / 9.0%。写正文时先说清用的是哪个分母。

### 11.21 课内 FE 用去均值实现时 SE 会低估（study42）

`groupby().transform(lambda s: s-s.mean())` 做的 LPM-FE，方差**未做自由度校正**（被吸收的 G 个课级截距没扣）。N=34,599、G=1,975 时低估约 **3%**，p 值偏小一点点。量级小、不足以改变任何显著性判定，但**若结论卡在 p≈0.05 附近必须做校正**，并在局限里写明。

### 11.22 分组赋值的顺序：细分必须写在粗分之后（study44）

`df.loc[cond, "grp"] = "A"` 之后再写 `df.loc[cond2, "grp"] = "B"`，若 `cond2 ⊂ cond`，前者会被后者**静默覆盖**。study44 中先写"真索理"（801 条）再写"索理核心"（765 条），结果"真索理"只剩 36 条（801−765），而代码不报任何错。**自检**：每组写完立刻 `print(df.grp.value_counts())`，核对总数与预期一致。顺序规则：**粗分类写在前面，细分类写在后面。**

### 11.23 组合检验时不要把待检验变量自己当控制变量（study44）

检验"短 × 点名"的叠加效应时，若同时把 `qlen_c`（长度）和 `indiv`（点名）放进控制变量，等于用自己控制自己 → 系数被强行拉回 0、甚至变号（study44 首轮得"短且点名 −7.9pp"）。**规则**：检验某变量的效应时，控制变量里**不得包含该变量的任何函数**；检验交互项时，只控制与交互项无关的协变量。多分类主类效应同理。

### 11.24 课内 FE 的功效取决于"组内变异"，不是样本量（study44）

同一套数据，对照集选"同课其余**同类**提问"→ 可对照课仅 106 节、大部分类别不显著；改成"同课**其余全部**提问"→ 3.5 万对照、1975 课、效应全部显著。**规则**：写课内 FE 前先数 `groupby(lesson)["处理"].transform("size")` 的可用课数；**小于 200 时结论只能当辅助证据**，主结论仍以原始产出率 + 简单组内差呈现，并写明"未检出 ≠ 无效应"。

### 11.25 同一文件严禁并行多个 Edit（v5.0 终稿批踩坑，2026-09-24）

在同一消息批次里对**同一个文件**发多个 Edit 调用会发生读-改-写竞态：各调用基于同一份原文各自修改，后写者覆盖先写者，且每次调用都返回"成功"——丢改无任何报错。v5.0 终稿批因此丢失两处数字修正，靠 grep 复核才发现旧值残留。

- **规则**：同一文件的多处修改必须**串行**（一个 Edit 返回后再发下一个）；不同文件才可并行。
- **自检**：每轮编辑后 `grep -c "新值"` 与 `grep -c "旧值"` 双向核验，旧值计数必须为 0。

### 11.26 补做双人编码信度时，抽样不得按首轮类别分层（study46）
- **分层＝泄题**：若按首轮 code 做分层抽样，样本构成本身就把首轮标签泄露给第二轮编码者，κ 虚高且无法辩护。一律**简单随机抽样**＋固定种子。
- **盲样只给原文**：`blind_sample.txt` 只输出编号 + 原始话语，不带 code、不带 flags、更**不带任何产出标签**（说理/高阶），否则编码会被结果带偏。
- **先封存再开封**：首轮标签写入 `sealed_first.csv`，由开封脚本一次性读取比对；开封后**不得回头改 codes_blind.csv**，否则 κ 作废。
- **coded_short.csv 没有 idx 列**：它是按 rs==1 子集顺序 concat 出来的，行号 0..976 才是全局 idx；与 events_aug 对齐时必须用 `e.index[e.rs==1][i]`（同 11.22）。
- **κ 要报 CI 并配聚合层**：单报 κ 不足以说明分歧性质。补做"开封前即可确定"的聚合层（如二分"是否索理"），证明分歧不跨实质边界——聚合方案必须先验确定，不能看完分歧再反推。
- **κ 必须与 Pe 同看**：只看 κ 会被期望一致率骗过去。极端不均衡的类别（如某标记两轮都几乎不打，Po=0.97 但 Pe=0.93）κ 数值很脆、CI 极宽，须在论文里降调或弃用。
- **最关键的第三步是稳健性，不是 κ**：把部分标签换成第二轮后**重跑正文同一个模型**，看效应排序是否翻转（Spearman ρ）、首位末位是否变。这一步比 κ 本身更能回应答辩质疑。
- **自验照旧**（见 11.13）：先跑"全第一遍标签"必须与原始 script 输出逐位复现（本轮偏差 0.0000pp），才敢采信"替换标签后"的结果。
- **诚实边界必须写明**：若两轮由同一底层模型完成，κ 只能报告为**编码方案的可复现性上界**，明文说明不等同人类评分者间信度，并给出补测人类编码者的成本估算。

### 11.27 报告里的百分比必须当场与并列的条数对账（v5.0 漏网错误，2026-09-24）
- **症状**：正文写"15.7% 根本不是索理"，紧跟着并列列举了"89 条＋64 条＋36 条"——89+64+36=189 条，占 977 的 **19.3%**，与 15.7%（实际只对应 NONE+VAG 的 153 条）对不上。**这一条从 v4.1 一路活到 v5.0 终稿，历经多轮审阅与"终扫"都没被抓到**，因为终扫只查了"弃用值零残留"，没查"比例与基数是否自洽"。
- **规则**：任何"X% + 若干条"的表述，交付前必须用脚本把列举项求和、除以总数、与百分比比对。**尤其当同一段里既给比例又给条数时**。
- **派生规则**：同一个概念在代码里有多个口径（`genuine` 7 类 vs 索理核心 5 类 vs 非索理 NONE+VAG(+EXT)）时，**正文必须显式写明用的是哪一档**，并与代码分层变量同名对应；否则正文的定性描述（"命名/表态不算索理"）会和代码的分类（把 MEAN/META 计入 genuine）直接打架。
- **脚本侧**：**禁止硬编码"全量基准值"**（如 `print("全量 977 条口径为 84.3%")`）。基准一律从数据现算，否则基准会随口径修订而悄悄过期。
- **终扫清单要加一项**：不只扫"弃用值残留"，还要扫"比例×基数自洽"（本次修正见 `02_报告与审查/v5.0修订说明…` 第 30 条）。

### 11.28 md→docx 转换链路的两个隐形坑（2026-09-24，build_final_docx.py）
- **坑一：源码里的不可见占位符字符会被写入链路吞成空串**。为解析 `\*` 转义星号，用私有区字符 U+E000 做占位符时，若把该字符**直接写在源码字符串里**，经编辑工具写入后会变成空字符串 `""`——随后 `text.replace("", STAR_REPLACE)` 会在**每个字符之间**插入替换串，全文文本被插入星号且结构上完全看不出异常（段落数、表格数都正常）。
  - **规则**：占位符一律用显式转义写法 `STAR = "\uE000"`，禁止在源码里直接写不可见字符；生成后必须抽查 `chr(0xE000) not in text` 且抽查连续词（如"摘要"）能整体命中。
- **坑二：`re.sub` 替换串中的 `\u` 会被当转义符报 `bad escape \u`**。替换串含反斜杠时（哪怕是 `chr(92)` 拼出来的），必须用 `re.sub(pat, lambda m: s, text)`。
- **配套规则**：论文 md 源的显著性星号统一写作 `\*\*\*`（转义），禁止裸写 `pp***`——裸写会与粗体标记 `**` 歧义（本次附录.md 一处，已修）。
- **md→docx 自验清单**：图片数核对、关键数字字符串命中、U+E000 零残留、反斜杠零残留、粗体 run 抽查 `bold==True`、表格行列数抽查。
