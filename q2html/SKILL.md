# Q2HTML · 习题课件生成（题目+答案 → 单文件 HTML）

把一节课或一整章的题目与解析，做成能直接发给学生、能投影、能手写批注、能导出 PDF 的网页。

## 工作流（三步）

### 1. 把来源转成「课时文本」

**不管来源是什么，先转成"一节课一个文本文件"**，格式见 `references/schema.md`：

```
lessons/
├── 01_指数的基本运算.md
├── 02_同底对数的基本运算.md
└── ...
```

各来源的具体做法见 **`references/sources.md`**：

| 来源 | 做法 |
|---|---|
| ima 知识库 | 用 ima 连接器取课时的 markdown（**PDF 有原版/去水印两版，选 introduction 里带 `$` 公式的那个**），存成 `NN_课时名.md` |
| Word (.docx) | `python3 scripts/docx_to_text.py 题目.docx -o 01_课时名.md`（自动把 Word 公式转 LaTeX） |
| PDF / 扫描件 | 先用 `wpscli` 技能转成 Word，或 `glmocr-formula` 技能 OCR 公式，再走上面两条 |
| 纯文本 / 网页 | 按格式整理成一个文件，无需转换 |

文本的书写习惯（解析器认这些）：
- `1.` `2.` 开头的题号行 = 新题目，**必须从 1 开始且连续**
- `（1）` `(1)` = 子问（自动缩进）；`A.` `B.` = 选项（自动并排）
- 公式用 `$...$`（行内）、`$$...$$`（独立成行）写 LaTeX
- `（解析）` = 题目区/答案区分界；答案区每题用 `1.` `2.` 开头
- `【提升】【综合】【拓展】【挑战】` = 切割线，**之后内容全部丢弃**（只保留基础题）

### 2. 一条命令生成 HTML

```bash
python3 scripts/build.py --src <课时文本目录> --title "08_函数-指数、对数运算" --out <输出.html>
```

常用参数：
- `--manifest x.json`：课时文本文件名不是 `NN_名字.md` 格式时，用它指定序号与名称
- `--kicker "高一数学 · 课后习题"`：封面小字（默认就是这个）
- `--keep-all`：保留【提升】等进阶题（默认丢弃）
- 只改 JSON 不动文本时：`node scripts/render_deck.js deck.json out.html`

脚本会打印每节课的「题数 / 解析数」，**两者不等会提示**——先处理提示再交付。
中间产物 `<输出名>.deck.json` 留在输出旁边，方便手改后单独重渲染。

### 3. 交给用户 + 自检

- 用 `present_files` 打开生成的 HTML（会自动起预览），让用户直接看。
- 改过版式/打印/手写相关代码后，**必须**跑自检：

```bash
node scripts/verify_deck.js <输出.html>            # 需要浏览器路径时可传第二个参数
node scripts/zoom_test.js <输出.html>              # 动过缩放/橡皮/手写层时加跑
```

自检三项：① 内容不被左下角工具栏遮挡 ② 打印导出准备正常 ③ 笔迹跟着内容滚动。
`zoom_test.js` 另测 19 项：缩放面板、放大后宽度不溢出、按钮/键盘、橡皮三档循环、打印复位。

## 输出课件里有什么

- **封面 + 目录**：目录可点击跳转；大标题自动去掉开头的章节序号
- **两题一页**：同一课时内两题一页，第一题靠上、第二题居中，中间和下方留出写板书/批改的空白；某课时只有一题就只放一题
- **答案折叠**：点「答案与解析」展开，含分步解析
- **✎ 手写**：黑笔/红笔/橡皮/清本页/清全部；笔迹按页面内容坐标存储，页面滚动时跟着内容走；触屏双指可翻动内容
- **橡皮可调粗细（三档）**：点「橡皮」进擦除模式，**再点循环 细(14px)→中(26px)→粗(44px)**，按钮实时显示当前档（橡皮·中）；每笔自带擦除尺寸，换档不会让已擦的笔迹变形
- **放大/缩小滑块（右上角 Aa）**：点开拖滑块 80%~200%（或 −/＋ 按钮、键盘 `+` `−` `0`），只放大题目内容、工具栏和页码不动；放大后宽度自动锁在视口内，只往下滚。**明确不用 Ctrl+滚轮缩放**（课堂易误触）；导出 PDF 自动按 100% 输出
- **⛶ 全屏（快捷键 F）**：字号随屏幕短边同步放大，4K 白板 46px
- **打印/存PDF（矢量）**：走浏览器原生打印管线，整章 19 页约 0.4 秒、400KB，文字可选中、放大不糊、手写批注一起导出。用户需在打印对话框里把目标选成「存储为 PDF」
- **多设备适配**：手机 / 平板 / 投影都能用，右下角翻页（按钮 + 键盘方向键）

## 脚本一览

| 脚本 | 作用 |
|---|---|
| `scripts/build.py` | 一键：课时文本目录 → deck.json → HTML |
| `scripts/parse_questions.py` | 单节课文本 → 结构化题目 JSON（解析器核心，可单独用） |
| `scripts/render_deck.js` | deck.json → 单文件 HTML（含手写层与打印导出） |
| `scripts/docx_to_text.py` | Word(.docx) → 课时文本（OMML 公式转 LaTeX） |
| `scripts/pdf_to_lesson.py` | PDF → 课时文本（文字层 + 公式图按阅读顺序合并） |
| `scripts/verify_deck.js` | 生成的 HTML 自检（遮挡 / 打印 / 手写） |
| `scripts/zoom_test.js` | 内容缩放滑块 + 橡皮三档实测（19 项：--z/宽度不溢出/按钮与键盘/橡皮循环/打印复位） |

渲染器版本：**V5（2026-10-17 定版，最终版）**。含 手写掌拒/合并采样/静态层渲染/采点降密/缓存只留当前页。
改动渲染器前**务必先读 `references/pitfalls.md`**，并按其中第 9 节先建版本快照。

依赖：Python 侧只需标准库（Word 路径另需 `python-docx`）；Node 侧 `mathjax-full`、`perfect-freehand`
（自检另需 `puppeteer-core`）。首次运行会自动装到本技能目录的 `.deps/`（约 80MB，是依赖缓存，
打包分享时可整目录排除），若沙箱拦了 npm 会提示手动安装命令。

## 课堂小插件（可选，build.py --widgets 开启）

6 个可多选的小插件，`--widgets plant,pace,focus,roll,exit,allans`（逗号分隔，留空=只有计时器）：

| 插件 | 效果 | 依据 |
|---|---|---|
| `plant` | 右下角「下一页」上方，植物随翻页生长（6 阶段） | 进度可视化 + 拟物化身（元分析里对成绩效应最大的元素） |
| `pace` | 顶部 3px 细进度条 | 目标梯度 |
| `focus` | 开启后本页题目压暗，点某道题→**整道变亮**；↑/↓ 换题，Esc 退出 | 多媒体"信号原则"（无课堂 RCT，低风险） |
| `roll` | 随机抽问：全屏滚学号，人数可设并记住 | cold calling ↑ 学习/检索（抽学号不抽名，降焦虑） |
| `exit` | 要点卡：下课前 2 分钟三条提示 + 120 秒 | exit ticket + 检索练习 |
| `allans` | 本页答案全部展开/收起，翻页复位 | 便利 |
| `plant-tl` | 把植物放回左上角（默认在右下角「下一页」上方） | 位置偏好 |

刻意**不做**排行榜/积分（元分析里对动机是负向）。全部插件在打印 PDF 时自动隐藏。
进度植物默认在右下角「下一页」按键上方（那一带是翻页区留白，不占内容空间）。
植物旁的 `12/12` 页码是**保留的**——翻页键中间已不再显示页码，页码只在这里出现。

### 工具栏（右上角）

计时器、全屏和插件按钮都挂在右上角同一个 `.tmr` 工具栏里，从左到右：

```
⛶ 全屏 | ⏱ 计时 | 🔍 专注 | 🎲 抽问 | 🎫 要点卡 | 📖 答案全开 | 🔀 换一批
```

- `⛶ 全屏`（`#bFs`，快捷键 `F`）是 2026-10-21 从 **l2html 技能**移植过来的：
  一键进/出全屏，`fullscreenchange` 事件同步按钮文案与 `.on` 态，Esc 也能退出。
  它的真正作用是**把 vmin 从「窗口尺寸」变成「屏幕尺寸」**——浏览器只开一半时，
  点了全屏字号才会随屏幕放大。**≤620px 自动隐藏**（手机本身即全屏应用，且 iOS 不支持元素全屏）。
- `🔀 换一批` 由练习页自己挂载，**只在停在练习页时出现**，其他页自动隐藏。
- **手机上这些按钮一直带文字**（2026-10-19 改）。以前 ≤860px 会隐藏文字、只留一个
  16×13px 的裸 emoji，用户反馈「手机上看不到、也不知道点什么」，遂取消该规则；
  同时把点击热区从 25px 抬到 32px。
- 代价是按钮会换行：390px 屏上五个按钮一行、`换一批` 单独一行；≤400px 则两行。
  所以 `.slide-prac` 的 `padding-top` 兜了 `max(..., 56px)` 下限，≤860px 再升到
  `pad-y + 78px`，≤400px 给题目页也补 `pad-y + 66px`——否则页眉/第一题会被工具栏压住。
- 改这块务必按 13 档视口（320/360/375/390/430/560/768/860/900/1024/1280/1440/1920）
  跑一遍「工具栏矩形 vs 页面真实文字矩形」的相交检测，**只比纵向位置会误判**
  （`.prac-hd` 是全宽容器，但文字只在左边）。

### 字号随屏幕缩放（全屏的意义）

`--u: clamp(17px, 2.4vmin + 10px, 46px)`。**上限 46px 是 2026-10-21 从 30px 抬上去的**
（原来 4K 白板上字被锁死在小屏尺寸）。小屏完全不受影响——cap 只在 vmin > 833px 后才起作用：

| 视口 | 正文字号 |
|---|---|
| 390×844（手机） | 19.4px |
| 1280×720 | 27.3px |
| 1366×768（老投影） | 28.4px |
| 1920×1080 | 35.9px |
| 3840×2160（4K 白板） | 46px |

代价：**练习页一屏能放的题数会变少**（字号不缩，只减题数）。以周考卷（题目较长）实测，
1920×1080 约 2~4 道、1366×768 约 2~3 道；3.1 那份短题仍是 4~5 道。

已停用（函数体还留在 `WIDGET_JS` 里，想恢复就把对应行加回 `INITS`）：

| 插件 | 原效果 | 停用时间 |
|---|---|---|
| `nudge` | 每 12 分钟弹一次「上课休息一下」活动提醒 | 2026-10-19 |
| `vote` | 🙋‍♂️ 懂/模糊/不懂 三键计数 | 2026-10-19 |

## 随机练习页（最后一页，自动生成）

课件**最后会多出一页「本节小练」**，用于大屏展示、学生在本子上做题：

- **封面目录下方有一行独立入口「✏ 本节小练」**，点了直达这一页。
  它不在两栏的课时目录里——放进去会随课时数在左右栏之间漂移，单独一行位置永远固定。
- 从**全部题目**的题干里随机抽 **4~6 道**（上限由 `render_deck.js` 的 `PRAC_MAX` 决定，
  构建期写进 `data-max`，运行时读取，改一处即可）
- **只写题干**——不带答案折叠、不留板书空隙，题间距压到最小
- **字号绝不缩小**，始终沿用正文 `var(--u)`；放不下就少放一道，而不是缩字
- 题数按**实际可用高度**自适应，实测（字号抬到 46px 上限后，2026-10-21 复测）：

  | 视口 | 题数 | 字号 |
  |---|---|---|
  | 1920×1080 | 2~6 | 35.9px |
  | 1600×900 / 1440×900 | 2~5 | 31.6px |
  | 1366×768 / 1280×720 | 2~4 | 28.4 / 27.3px |
  | 1024×768 | 3~4 | 28.4px |
  | 810×1080（平板竖） | 2~4 | 29.4px |
  | 390×844（手机） | 1~3 | 19.4px |

  题数区间来自**同一视口连抽三次**（抽题随机、题目长短差别大，单次数字说明不了问题）。
  长题目（如解答题多子问）会显著压低排数；短题课件（如 3.1 那份）在 1920×1080 稳定 5 道。

- `🔀 换一批` 按钮挂在计时器工具栏里，**只在停在练习页时露出**，其他页自动隐藏；
  切换用 `display` 切换，不会撑动工具栏
- **缩放窗口只重排、不重抽**：题目不变，只按新高度决定显示几道（rAF 节流）
- **翻页离开再回来，题目不会变**——只有点「换一批」才重新随机（老师来回翻页时更稳）
- 练习页**不滚动**，一屏放下；底部已避开 nav 与手写工具栏
- 题库不足 3 道时**不生成**这一页（避免出现只有一两道的练习页）

改这块前先看 `references/pitfalls.md` 的第六～十节，六个必须知道的点：
- 测量内容高度用 `last.getBoundingClientRect().bottom - box.getBoundingClientRect().top`，
  **不能用 `box.scrollHeight`**——box 是 `flex:1`，`scrollHeight` 永远等于 flex 给它的高度。
- `.prac-box` 需要 `flex:1 1 auto;min-height:0;overflow:hidden`，且要写
  `.sinner.prac>.prac-box` 提高特异性，压过通用规则 `.sinner.prac>*{flex:0 0 auto}`。
- PRAC_SCRIPT 注入在 `.tmr` 工具栏**之前**，所以挂「换一批」按钮必须等 DOMContentLoaded。
- 练习页里高公式（分段函数/大分式）必须 `vertical-align:middle`，否则整行文字被顶到公式下面。
