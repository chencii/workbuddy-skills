# 数据格式（两层契约）

整个流程只有两个东西需要对齐：**课时文本怎么写**，和 **deck.json 长什么样**。
前者是给人/AI 看的书写习惯，后者是给渲染器的严格结构。

---

## 一、课时文本的书写习惯（输入端）

一个文件 = 一节课。文件名推荐 `序号_课时名.md`，例如：

```
lessons/
├── 01_指数的基本运算.md
├── 02_同底对数的基本运算.md
└── 03_不同底对数基本运算.md
```

文件内容按这个习惯写就行（Markdown 或纯文本都可以）：

```markdown
1. 计算下列各式：
（1）$2^3 \cdot 2^4$；
（2）$\left(\frac{1}{2}\right)^{-2}$。

2. 化简：$\lg 4 + \lg 25$。

3. 已知 $\log_a 2 = m$，求 $\log_a 8$。
A. $3m$    B. $m^3$    C. $m+3$    D. $2m$

（解析）

1. 第 1 题解析
（1）由同底数幂相乘，$2^3 \cdot 2^4 = 2^{7} = 128$。
（2）$\left(\frac{1}{2}\right)^{-2} = 2^2 = 4$。

2. $\lg 4 + \lg 25 = \lg 100 = 2$。

3. 由 $\log_a 8 = \log_a 2^3 = 3\log_a 2 = 3m$，选 A。

【提升】
4. 这题及之后的都会被丢弃……
```

### 解析器认得的规则

| 写法 | 含义 |
|---|---|
| `1.` `2.` `3.`（阿拉伯数字 + 点/顿号/冒号） | 新题目开始，**必须连续递增** |
| `（1）` `(1)` | 子问，自动缩进一级 |
| `A.` `B.` `C.` `D.` | 选项，连续的选项自动并排 |
| `$$ ... $$` 单独成行 | 独立公式，放大按行显示 |
| `（解析）` `1. 试题解析` `答案：` | 题目区 / 答案区的分界 |
| `【提升】【综合】【拓展】【挑战】` | 切割线，**之后的内容全部丢弃**（只保留基础题） |

要点：
- 公式一律用 `$...$`（行内）和 `$$...$$`（独立成行）写 **LaTeX**，渲染时会变成矢量 SVG。
- 题号必须从 1 开始且连续；跳号会让后面的题被当成题干续行。
- 没有答案的题也能渲染，只是那一题不出现「答案与解析」按钮。

## 二、deck.json（渲染器的输入）

由 `build.py` 自动生成，也可以手写/手改。

```json
{
  "title": "08_函数-指数、对数运算",
  "chapter": "08",
  "kicker": "高一数学 · 课后习题",
  "lessons": [
    {
      "no": "1",
      "name": "指数的基本运算",
      "questions": [
        {
          "blocks": [
            { "type": "para", "label": "1.", "frags": [["t", "计算下列各式："]], "display": false },
            { "type": "para", "label": "(1)", "frags": [["m", "2^3 \\cdot 2^4"]] },
            { "type": "para", "label": "(2)", "frags": [["m", "\\left(\\frac{1}{2}\\right)^{-2}"]] }
          ],
          "ans": {
            "steps": [
              { "label": "(1)", "frags": [["m", "2^3 \\cdot 2^4 = 2^{7} = 128"]], "display": false },
              { "label": "(2)", "frags": [["m", "\\left(\\frac{1}{2}\\right)^{-2} = 2^2 = 4"]], "display": false }
            ]
          }
        }
      ]
    }
  ]
}
```

### 字段说明

| 字段 | 说明 |
|---|---|
| `title` | 章节大标题。渲染时**自动去掉开头的序号**（`08_函数-指数、对数运算` → 页面显示「函数-指数、对数运算」） |
| `kicker` | 封面小字，默认「高一数学 · 课后习题」 |
| `lessons[].no` | 课时号，显示在每页左上角的小方块里 |
| `lessons[].name` | 课时名，显示在课时号右边 |
| `lessons[].questions[].blocks` | 题干块数组 |
| `lessons[].questions[].ans.steps` | 解析步骤；没有 `ans` 就不显示答案按钮 |

### block 的三种形态

```json
{ "type": "para", "label": "1.",  "frags": [["t","文本"], ["m","x^2"], ["t","。"]] }
{ "type": "para", "label": "(1)", "frags": [["m","..."]] , "display": true }
{ "type": "opts", "items": [ {"label":"A","frags":[["m","3m"]]}, {"label":"B","frags":[["m","m^3"]]} ] }
```

- `label` 决定行首编号与缩进：`1.` `2.` 是顶层，`(1)` `①②` 自动缩进一级，空字符串是**续行**（也缩进一级）。
- `frags` 是「文本 / 公式」交替的数组：`["t", 纯文本]` 或 `["m", LaTeX]`。
- `display: true` 让公式按 `\displaystyle` 放大（分式、分段函数、根式更接近卷面）。
  解析器会自动判断：整行只有一个大分式/`cases` 时也会自动放大。

## 三、文件命名与顺序

`build.py --src <目录>` 的排序规则（二者取先）：

1. 文件名开头的数字：`01_...` → 1，`2_...` → 2，`1.2_...` → 1.2
2. 没有数字前缀时按文件名的自然排序，序号 = 序号位

课时名 = 文件名去掉 `序号_` 前缀后的部分。
如果文件名不是这个格式（例如 ima 导出的 `08-01.md`），用 `--manifest` 指定：

```json
[
  { "md": "08/08-01.md", "lesson_no": "1", "lesson_title": "指数的基本运算" },
  { "md": "08/08-02.md", "lesson_no": "2", "lesson_title": "同底对数的基本运算" }
]
```

也接受简化写法 `{ "08-01.md": { "no": "1", "name": "指数的基本运算" } }`。
