# 手写笔记照片批量转录

把散乱的手写照片变成一份可读、已勘误、有页序的文稿。

## 核心难点（先看这条，能省一半时间）

**43 张图 ≈ 5~8 万 token。一次性读完再写稿，中途上下文被压缩会丢失已识别内容，且图片内容不会自动恢复到后续轮次。**

所以必须：**分批读图 → 立刻落盘 → 再读下一批**。每批 10~13 页写一次文件，用 `<!-- APPEND -->` 占位标记做追加锚点，后续用 Edit 替换它。

## 执行流程

### 1. 清点 + 定页序

```bash
ls -la <目录>/ | wc -l
```

**定页序的优先级**（文件名常是随机 UUID，不可用）：

1. 文件系统创建时间（`mdls -name kMDItemContentCreationDate -raw` on macOS）—— 注意：经过 iCloud 同步的图片**这个时间会全部相同**。
2. **EXIF 原始拍摄时间** —— 最可靠。连续拍照的时间戳间隔 3~5 秒，天然就是页序。
3. 照片内容里的页码/日期/标题。
4. 内容连续性（上一页末句接下一页首句）。

生成顺序表并让用户可核对：

```bash
cd <目录> && for f in *.jpeg; do t=$(mdls -name kMDItemContentCreationDate -raw "$f"); echo "$t|$f"; done | sort | \
while IFS='|' read -r t f; do i=$((i+1)); printf "%02d\t%s\t%s\n" "$i" "$t" "$f"; done > outputs/_顺序表.txt
```

### 2. 分批读图转录

- 用 Read 工具读图，**一次并行发 3~6 张**，避免单轮返回过多。
- 读图时**在思考里只记要点**，详细转录直接写进文件，不要写两遍（思考里一遍、文件里一遍 = 双倍 token）。
- 每批读完立刻用 Write（首批）/ Edit（后续）落盘。

### 3. 模糊处裁剪放大核对

手写体的下标、系数、符号最容易读错。用 PIL 裁剪感兴趣区域并放大 3 倍：

```python
from PIL import Image
im = Image.open(path); W, H = im.size
c = im.crop((int(x0*W), int(y0*H), int(x1*W), int(y1*H)))
scale = min(3.0, 1800.0/c.width)
c = c.resize((int(c.width*scale), int(c.height*scale)), Image.LANCZOS)
c.save(out)
```

Python 环境用 `/Users/cc/.workbuddy/binaries/python/envs/default/bin/python`。

### 4. 勘误（这一步才是真正的增值）

**不要只做转录。** 笔记里通常有笔误、漏算、未完成。用内容自身的逻辑去反推：

- **数量级校验**：把结果代回原式验算。第 2 页「配凑法得 2」明显不对，实际应为 4。
- **内部一致性校验**：同一题在不同页出现时，答案必须一致。第 18 页判别式漏了系数（`5k²` 应为 `25k²`），修正后结果 `10/13 ≤ k ≤ 10/3` 恰好与第 19 页一致 —— 这是互相印证的强证据。
- **系数反推**：从推导过程中出现的系数反推原题。第 18 页推导里 x²、y² 系数同为 `(4k−5)`，说明原题二次项系数应相等（A=C），于是判定原题写漏了一个系数 4。
- **取等条件必查**：用基本不等式/柯西后，一定回代验证等号能否取到。第 14 页 `1/(a+1)+1/(b+2) ≥ 1` 的取等条件推出 a=1、b=0，与 a,b>0 矛盾。
- **题目本身可能有错**：区分「解法错」和「题目错」。遇到三项乘积非常数、或是强行套用齐次化却不满足齐次条件的情况，应判定为题设缺陷。
- **两种解法结果不一致 = 红旗**：第 11 页柯西得 ≥5 而乘 1 法得 ≥25，说明取等条件不兼容，列为待核对。

勘误的呈现方式：
- 页内用引用块 `> ⚠️ **勘误**：...`，紧跟在出问题的位置后面。
- 文末再给一张「勘误汇总表」（页码 / 类型 / 问题 / 修正）。
- 另附「待核对清单」—— 无法确定的地方诚实标出，不要硬圆。

### 5. 成稿结构

```markdown
# <标题>（整理稿）

> **来源**：手写笔记照片 N 张（拍摄时间范围）
> **排序依据**：EXIF 原始拍摄时间 = 原稿页序
> **整理方式**：逐页文字提取 → 内容勘误 → 按页序排版
> **符号说明**：用 Unicode 数学符号（≥ ≤ √ ² ⟳ ∴），便于复制到 Word
> **勘误标记**：凡笔误/漏算/结论有误处，用 `> ⚠️ 勘误：` 标出

## 第 1 页
...正文...

## 第 N 页
...

---

# 附：全稿总结
## 一、知识地图（表格：专题 → 页码）
## 二、方法口诀速记
## 三、勘误汇总表
## 四、待核对清单
```

## 注意事项

- **数学符号用 Unicode 而非 LaTeX**（`√ ² ³ ≥ ≤ ⟹ ∴ ∈ ∞ ⁿ`）。用户常常要复制进 Word 编辑，LaTeX 源码在普通编辑器里不可读。
- 表格里的公式也用 Unicode，不要为了排版牺牲可复制性。
- 原稿留白或只有标题的部分，明确写「（原稿仅列标题，无内容）」，不要凭空补内容 —— 但可以在勘误块里给「补充解答」，并标明是你补的。
- 中间产物（裁剪图、脚本）放在 `.tmp_seq/`，交付后告知用户可删。
- 如果原稿是《观课议课记录本》这类印刷表格纸，正文区在中间一栏，页脚有「课后反思」栏 —— 转录时要注意分辨哪些字属于哪一栏。
