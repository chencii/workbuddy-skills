# 孙宇晨访谈思想库（制定计划的思想依据）

> 来源：B 站 BV1fcHD6cEw3《对话孙宇晨：年轻人如何抓住 AI 时代的机会》
> 主持人邵艾伦（Alan）访谈孙宇晨。以下为按主题整理的思想要点，供制定计划时检索依据与引用原话。
> 说明：均为受访者本人的观点，属个人主张，不等于事实判断；引用时注意这一点。

---

## 1. 四套理论框架

| 理论 | 解决的问题 | 具体做法 |
|---|---|---|
| 孙学 | 认知 / 操作系统升级 | 更新对金钱、财富自由、万事万物的理解；理论先武装自己 |
| 搏击（健身） | 身体健康 | 力量训练为主、控热量缺口；被动燃脂；肌肉是"储蓄" |
| 黄毛 | 心态 | 不被外界评价裹挟，认定对的就充分执行 |
| AI | 工具 / 掌舵者 | 百分百信任 AI，AI 为主（约 90%），自己微调 |

四者关系：孙学管思想，搏击管身体，黄毛管抗压，AI 管执行。强调**零成本可起步**（有手机即可）。

## 2. 认知先行

- **"没有智商，只存在信息的多少。"** 用大模型类比：GPT 3→5 表面是智商差距，本质是灌进去的信息量差距（约 1000 倍）。
- 认知 → 行为 → 结果。根据新信息真的做出行为改变，就是在"提升智商"。
- **计划的起点是补信息，不是定动作。** 信息足够之后，决定自然浮现，不需要"赌"。

## 3. 先开图，再决策

- **"看 100 套房再买"**：重大决定前把样本看够，形成自己的 benchmark。
  - 择时模型：前 3 套绝对不买（用来建立基准），第 4–6 套出现优于基准的立刻出手（涉及黄金分割 0.618）。
- **游戏类比"开图"**：玩红警/星际先派斥候探图，而非闷头造兵；现实里先查 100 个专业的就业再选方向。
- 信息是免费探的；图打开了，决定就清楚了。

## 4. AI 为主

- **"百分百相信 AI"**，AI 为主（约 90%），自己做 10% 的微调。
- 多问几个模型（Claude / ChatGPT / Gemini）取中策。
- 他自己用 Claude Code 管健身：拍餐桌照算卡路里、读睡眠数据、录训练视频、每天出日报，全部可视化、数据化、可总结。
- 建立个人数据文件夹（MD 文档），所有数据数字化后交给 AI 分析，让它帮找方向。

## 5. 保持机动（逐水草而居）

- 游牧民族"哪有水草就去哪"；放到今天就是**哪里能发挥最大价值就去哪里**——地理位置、赛道、资产都保持机动。
- **反对过早买房买车结婚**，理由是会把人生"定死"，错失"哪个地方招手就去哪"的机会。
- 别人问他为何花 600 万美元买一根香蕉而不买黄金珠宝：香蕉是流动的 IP、概念艺术、数字资产，可带走；"车房能翻译给机器吗？"
- 选择资产与机会时优先考虑**机动性强**的。

## 6. 健康是一票否决

- 触发点：AI 对他说 **"你物质上是富人，身体上是穷人"**。
- **寿命 100 分模型**：心肺 25 + 肌肉 25 = 50 分，靠力量训练可全部拿满；其余（基因、器官、牙、不吸烟不喝酒）靠花钱和运气。
- **肌肉 = 身体的储蓄账户**：生病、消耗时身体优先扣肌肉，所以趁年轻多吃蛋白质"存起来"。
- 反驳"四肢发达头脑简单"：应是"四肢发达、头脑也发达"，二者相辅相成。
- 反驳名人（马斯克/巴菲特/特朗普都不健身）：AI 反问——巴菲特是"自己走进餐厅"还是"被轮椅推进去"？肌肉量 30–40 岁到顶，之后每年降 1–2%，70 岁再练就晚了。
- **主动健康管理**：不是生病才去医院，而是没症状时主动监测指标、提前排雷。
- 区分**主动练出的肌肉**与**农民工被动练出的肌肉**：后者缺营养学、缺 progressive overload、缺主动管理。
- **正循环 vs 负循环**：练 → 睡得好 → 有时间练 → 更自律 → 更研究 AI → 赚更多，螺旋上升；胖 → 打降重药 → 掉肌肉 → 代谢更低 → 更胖，螺旋下降。

## 7. 创造大于消费

- 人类活动分两类：创造活动与消费活动。**纯消费没有意义**。
- 二者需要平衡，但现代人的问题主要是创造不够。
- 举例：李煜亡国是消费，写词是创造——所以留名的是词。

## 8. 小 ego

- **越成功越要保持小 ego** 才能持续吸收新东西（举张一鸣为例）。
- **屁股决定脑袋**：既得利益者最难更新版本；"一代版本一代神"。
- 计划要留复盘与更新节点，允许推翻自己。

## 9. 黄毛（抗噪）

- 认定对的事，不被外界评价推走，充分执行。
- 但要与前一条同时成立：抗噪 ≠ 拒绝证据。
- 心态上"做个异类"，因为异类才拿到大结果。

## 10. 全球最优值

- **"商机要全球性发现"**，不要只在自家门口开小店。
- 做全球性的生意，把全世界的人当客户。
- 中国是世界工厂，产能嫁接到全世界就是价值。
- 计划里要问一句："放到更大范围里，能不能发挥更大价值？"

## 11. 先上路（体验论）

- **玩家心态**：人生像地球 online，目前仍在探索期。
- **前 50% 先体验，不下结论**：知道得越多越不敢下结论（他去过太空后，连"为人类做贡献"这种早年意义都被打破）。
- **体验大于结论**，人生意义可能就是你体验的集合（引《瑞克和莫蒂》）。
- **"先上路，比想清楚为什么上路更重要。"**
- 但——体验不等于躺平：要在"正确的方向"上体验，主体是创造。

## 12. 参照系 / north star

- 每个人应有自己的 benchmark。他自选三个"门派"：马斯克（工程与科技）、巴菲特（金融与长期主义）、特朗普（个人 IP 与跨界），取三家之长而不只练一门。
- **不要过早定型、不要先入为主。**

## 13. 财富自由

- **"先自由，后财富。"** 自由是主观的、无门槛；财富是自由之后的副产品，二者互相加强形成飞轮。
- **财富是度量衡 / 积分**，受可接触经济活动的天花板约束（他举例：全球 GDP 约 50 万亿，个人很难超过其 1%）。
- **中彩票是催命符**：没有对应认知的横财会放大坏习惯。

## 14. 判断方法

- **只评判对错，不评判动机。** 不要因为一个人人品有争议就否定他做的事。
- 反对"动机论"式攻击：不要管他是不是蹭热度，要判断他说的东西对你有没有价值、是不是科学。

## 15. 关键原话摘录

- "你物质上是个富人，但身体上你现在是个穷人。"
- "没有智商，只存在信息的多少。"
- "先自由，后财富。"
- "开图（探路）比什么都强，先别急着下结论。"
- "商机要全球性发现，不要只在自家门口开小店。"
- "一代版本一代神，认知要不断升级。"
- "不要管他的动机，要看他说的东西对不对。"
- "先上路，比想清楚为什么上路更重要。"
- "只要大方向对，尽情去体验，没有体验是作废的。"
- "我的理论核心就是：认知决定命运。"

## 用于计划的映射速查

| 计划遇到的问题 | 对应的思想工具 |
|---|---|
| 不知道该选哪条路 | 先开图：看 100 个样本再决定 |
| 计划怕执行不下去 | 先上路：定一个 24 小时内能做的小动作 |
| 想 All in 某个方向 | 保持机动：改成可逆、留退出条件 |
| 进度紧、想熬夜赶 | 健康底线：一票否决，重排 |
| 计划空转没产出 | 创造大于消费：补创造活动 |
| 别人都说不行 | 黄毛：顶住噪音；同时小 ego：检查是否漏了新证据 |
| 目标设得很小 | 全球视野：换更大范围想一遍 |
| 计划做完就锁死 | 留版本更新口：定复盘节点与推翻触发条件 |
