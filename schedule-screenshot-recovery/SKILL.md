# 课表截图复原（schedule-screenshot-recovery)

## 何时用

- 用户给一张课表截图（常见：18 个班 × 5 天 × 11 节 + 夜自习的「全周总课表」），要求转成 Excel。
- 截图往往是从教务系统导出后**整体缩放**的，单格只有 ~40×26 px、字高 ~10 px。**整图 OCR 一定失败**，但会输出一堆「看起来像中文」的乱码，极易被误当成数据——绝对不要拿它交付。

## 铁律

1. **先测结构，再谈识别。** 不测网格就开始 OCR = 必然出错。
2. **能找源数据就不要 OCR。** 课表类截图的源 Excel 大概率就在用户桌面/工作区里（文件名常含「课表/优化版/最新版」）。找到后做一致率比对，确认是哪一版，然后直接复用——这是唯一能保证 100% 正确的路径。
3. **禁止猜填。** OCR 置信度低或与权威表冲突的格子，留空并标注，不要填「最像的」答案。
4. **交付前必须交叉验证**：与源文件逐格 diff，或与教师任课表互相印证（格内教师是否真是该班该科教师）。

## 步骤

### 1. 定方向 + 测网格（Python + numpy）

截图常被旋转 90°：用 Vision/OCR 测会发现文字框「宽 0.013、高 0.156」这类竖直比例，据此判断要 `rotate(270, expand=True)`。

网格线检测（暗像素占比投影法，实测可靠）：

```python
a = np.asarray(Image.open(p).convert('L').rotate(270, expand=True)).astype(int)
dark = (a < 140)
colf, rowf = dark.mean(0), dark.mean(1)          # 列/行暗像素占比
vlines = [i for i in range(a.shape[1]) if colf[i] > 0.5]   # 竖直网格线
hlines = [i for i in range(a.shape[0]) if rowf[i] > 0.8]   # 水平网格线
```

判读要点：
- 网格线占比接近 **0.94~0.97**（几乎全暗）；文字行只有 0.2~0.3。别把文字行当网格线。
- 间距规律即结构：如列距恒为 42 px（18 个班 + 两侧窄标签列），行距恒为 26 px，每 372 px 出现一条 34 px 的加宽带 → 说明「一个日块 = 表头行 + 11 节 + 夜自习」，5 个日块堆叠。
- 用表头行的文字框 x 坐标反查列归属，并用第 1 列标签（1…11、夜自习）确认行语义。
- **注意班级顺序可能是倒序**（实测 2618→2601 自左至右），要用表头行逐个读出确认。

### 2. 找源数据并判定版本（最优先分支）

候选文件通常在这些位置：`~/Desktop/*课表*.xlsx`、`~/Desktop/最新版.xlsx`、`~/WorkBuddy/*/outputs/**`。先按「18 班 × 5 日块 × (11 节 + 夜自习)、格内为『科目\n教师』」的结构特征筛出同族文件。

判定用「划分一致率」而不是肉眼比对：把每版 Excel 转成 `内容[班][日][节]`，对同班的 55 个格两两配对；图片侧对同样两两配对做**墨迹掩膜汉明距离聚类**（同一格内容重复出现时像素几乎相同，实测距离 0.001~0.01），然后统计
「(内容相同) == (像素同簇)」的配对比例。匹配版本会以明显优势胜出（实测 99.94% vs 其余 90~94%）。
脚本见 `scripts/match_version.py`（内含 `cols`/`blocks` 几何常量，换图后需按步骤 1 重新测量）。

> 这一步同时是**图片与源文件的一致性验收**：一致率 >99.9% 才可认为图片就是该版本。

### 3. 没有源数据时才逐格 OCR

- 按测出的网格切格 → 放大（LANCZOS 3~12 倍）→ 逐格送入 macOS Vision（`scripts/ocr_grid.swift`，可设 `customWords` 咬住科目/教师词表）。
- **同内容格子像素一致**这个性质可用来去噪与校验：列内聚类（并查集，掩膜汉明距离 <0.08）后，把同簇格子对齐求平均再识别，比单格识别稳。
- 字高只有 ~10 px 时预期准确率有限（科目常错成同形字：数学→效学、英语→羽识、化学→化券）。可用教师任课表反推科目（一个教师通常只教一科），并只保留双证据一致的格子。

## 交付

按 `tencent-docs-sheet-generation` 的 openpyxl 范式出表；课表类推荐 4 个 sheet：`总课表`（复刻原表：班级为行、5 个日块为列）、`班级课表`（每班一块：节次 × 周一~周五）、`教师课表`（每位教师一块，格内填班级）、`任课教师一览`（科目 × 班级矩阵）。配色克制：语数外浅蓝 / 理化生浅绿 / 政史地浅黄 / 体育艺术信息班会浅灰 / 自习近白。

## 已知坑

- `sips -r 270` 对 jpg 会因后缀告警改写方向不可靠，用 PIL `rotate`。
- 系统 tesseract 默认没装 `chi_sim`；macOS 自带 Vision 中文识别更强，直接用 Vision。
- 命名文件前先查重名，别覆盖用户既有文件。
- 用户说「文件命名为 X」时按用户给的落盘名，但位置优先沿用同类文件所在目录（课表族一般在桌面）。
