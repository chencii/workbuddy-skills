# 人工课表检查（schedule-audit）

## Overview

用户会在 Excel 里手动改课表（挪格/删格/加格），改完需要自动检查：① 教师同一时段是否冲突；② 每班每科的正课/自习数量是否达标（宽松版）；③ 半天没课/晚自习连贯等体验指标。

## 环境与路径

- 工作区：`/Users/cc/.qwenworkcn/workspace/mt7cq04avyu4ocg3/`
- Python：`/Users/cc/.workbuddy/binaries/python/envs/default/bin/python`
- 脚本：
  - `check_user_xlsx.py FILE.xlsx` —— 教师同段冲突 + H24 禁课时段（正课槽位口径）
  - `check_class_view.py FILE.xlsx` —— **班级×科目视角**宽松课时检查（主检查）
  - `check_teacher_load.py FILE.xlsx` —— 老师视角汇总 + 整天没课/半天空/下午空值晚自习

## 宽松口径（用户 2026-08-30 指定）

- **视角 = 班级 × 科目**（不是老师汇总）：一周之内，某学科在某个班**少一节自习没关系**。
- 属性判定：
  - 内容以"自习"结尾（含"XX自习"或"XX·自习"）→ 自习
  - 晚1晚2（槽位10/11）→ **无条件算自习**（不管是否标注）
  - 其余未标注的格子 → 算正课
- 宽松规则：
  - 正课必须满足标准（未标注节多出的部分按"自习"计，即正课多1节可容忍，但建议补标）
  - 自习允许 ±1 节（多1节或少1节都算宽松通过）
  - 正课不足或自习差 ≥2 → 不符合
- 每班每科标准课时：语文5正2自、数学6正2自、英语5正2自、物理4正1自、化学4正2自、生物3正2自、政治2正1自、历史2正2自、地理2正1自

## 操作步骤

1. 跑主检查（班级视角）：
   ```bash
   python check_class_view.py "/path/人工课表.xlsx"
   ```
   输出：完全符合 X 班·科 | 宽松 Y | 不符合 Z，然后列出不符合清单（班、科、老师、标准、实际、差额）和宽松清单（少1自习/多1自习/正课多1按自习计）。
2. 跑教师冲突 + H24：
   ```bash
   python check_user_xlsx.py "/path/人工课表.xlsx"
   ```
3. 跑老师视角 + 半天没课：
   ```bash
   python check_teacher_load.py "/path/人工课表.xlsx"
   ```
4. **报告给用户**：
   - 不符合的班·科（必须修）
   - 宽松名单（按"少1自习/多1自习/正课多1按自习计"分类）——这些是"灵活的人"，符合宽松要求
   - 教师冲突数、H24 违反、整天没课老师、下午没课却值晚自习的人次

## 关键陷阱

1. **合并表布局（必记）**：两块式——上半块行3-20=周一/二/三，下半块行24-41=周四/五；每 13 列一组（列1=班级、列2-12=槽1-11、列13=夜自习）+ 组间空 1 列；槽位 s → 列 `base+s`，`base=1+(d%3)*14`（d=0,1,2 → 1,15,29；d=3,4 → 1,15）。**每格公式错 1 位曾导致全表统计错乱**。
2. **用户手改格式**：可能把"·自习"改成"自习"（无点），解析时 `name.endswith('自习')` 判断，科目 = 去掉"自习"/"·自习"。
3. **老师视角 vs 班级视角结果不同**：老师视角会把"范康羽自习多2"这种（实际是 2 个班各多1）误判为严重，班级视角才是用户认可的口径。
4. **H24 禁课时段**：用户要求"该半天该科目老师不出现"（正课+自习全禁，含第3节）。check_user_xlsx 用正课槽位口径，如需含第3节口径需调整（上午 = [1,2,3,4,5]）。
5. **"正课多1节按自习计"的建议**：多出的未标注格建议让用户补标"XX自习"，即可从宽松变完全符合。

## 补充：半天没课检查（到校口径）

- 整天没课（休息日）：正常，无需处理
- 上午空/下午空但另一半天有安排：半天制正常结果
- **下午没课却值晚自习**（连贯性差，值得优化）：列出老师与星期，建议后续微调优先处理
