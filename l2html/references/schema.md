# content.js 数据规范（写内容前必读）

`content.js` 导出 `{ PAGES }`，`figs.js` 导出 `{ FIGS }`。渲染器只认这两个文件，
**排版全部由块类型决定，不要在 HTML 层面手工干预**。

## 页面结构

```js
const PAGES = [
  { type: 'cover', kicker, title, sub, lead, toc: [['一','学习目标'], ...], foot },
  { tag: '一 · 学习目标', title: '学习目标', time: '5 分钟', blocks: [ ... ] },
  ...
];
```

### 封面页（type: 'cover'，必须是 PAGES[0]）

| 字段 | 说明 |
|---|---|
| `kicker` | 封面顶部小字（如「第三章 函数的概念与性质」） |
| `title` | 大标题（如「函数的单调性」），同时用作 `<title>` 前缀 |
| `sub` | 副标题（如「3.2.1 单调性与最大（小）值　第1课时」） |
| `lead` | 引导语，可空串 |
| `toc` | 目录数组 `[中文数字, 名称]`，**键必须是「一/二/三…」且与页 tag 的开头一致** |
| `foot` | 封面底部小字（如「人教A版 · 必修第一册」） |

### 内容页

| 字段 | 说明 |
|---|---|
| `tag` | 页眉环节标签，**格式必须为 `一 · 环节名`**（中文数字 + 空格·空格 + 名称）。目录跳转靠这个开头匹配，写错格式目录全部失效 |
| `title` | 页眉大标题 |
| `time` | 页眉右侧建议时长，可省 |
| `blocks` | 块数组，见下 |

## 块类型（b.t）

所有文本字段 `c` 都走同一套行内语法：
- `$...$` 行内公式、`$$...$$` 独立成行公式（LaTeX，构建期转 SVG）
- `**加粗**`（可跨公式）
- `{{b}}` / `{{b2}}` = 学案里的填空横线（短/更短）

| t | 字段 | 用途 |
|---|---|---|
| `p` | `c` | 普通段落；`rv:true` 时纳入逐步揭示 |
| `lead` | `c` | 导学段（字号略大） |
| `ul` | `items:[str]` | 圆点列表 |
| `def` | `lab, c` | 定义卡（左侧粗边） |
| `note` | `kind: key\|tip\|warn, lab, c` | 提示卡三色 |
| `fig` | `key, cap?` | 插图，`key` 是 figs.js 里 FIGS 的键 |
| `tbl` | `head:[str], rows:[[str]]` | 三线表，`''` = 空格 |
| `steps` | `items:[{lab, c}]` | 编号步骤卡 |
| `chips` | `items:[str]` | ①②③ 胶囊行 |
| `eqline` | `c` | 公式行（居中） |
| `ex` | `no, c` | 「例 x」题号行 |
| `dt` | `lab, c`（`board:true` 加高） | 点拨/讲解行 |
| `num` | `no, c` | 「跟踪 x」题号行 |
| `sub` | `no, c` | 子问 `（1）` 行 |
| `opts` | `items:[[字母, 文本]]` | 选择题选项并排 |
| `solf` | `lab, c, fig` | 「解」+ 右侧图 |
| `sol` | `lab, c, fig?` | 「解」（图在下方） |
| `dtab` | `rows:[[{c?, fig?, h?, span?}]]` | 网格表，`h` 表头单元格，`span` 跨列，`fig` 插图单元格 |
| `board` | `tall?` | 板书演算空白区（留给教师现场写） |
| `grid` | `cols, items:[{lab, c}]` | 卡片网格 |
| `ans` | `lab?, c, fig?` | 折叠答案（点开） |
| `hint` | `lab?, c` | 折叠提示 |
| `qa` | `no, c, a` | 判断题 + 折叠「理由」 |
| `exa` | `no, c, a, lab?` | 例题 + 折叠答案 |
| `q` | `no, c, opts?, fig?, side?, a?` | 题目卡；`side:true` 图右文左，`a` 折叠答案 |

任何块加 `rv: true`（p/note/eqline 支持）即纳入「下一步」逐步揭示序列；
页面没有任何 rv 块时不显示揭示条。

## 分页与答案的摆放（用户红线，2026-10-20 定）

- **一页一个教学单元**：一个题型讲解 / 一道例题 / 一道跟踪题，不混排。
- **题和答案同页**：例题/跟踪题的解答用 `ans` 折叠块跟在题后面（点击展开），
  禁止题一页、解答下一页，也禁止把上个题的解和下个题型混一页。
- **下方留位置**：题页尾部放 `board`（证明类可用 `board tall`），页面自然停在
  60~80% 高度，不要排满贴到底部工具栏。连续的「例+跟踪」可同页（如题型三各角度），
  两者共用一个折叠的「参考答案」。

## figs.js

```js
const FIGS = {
  fig_inc: () => `<svg viewBox="0 0 420 260">…</svg>`,   // 返回 SVG 字符串
};
```
- 每个图形一个函数，**不要缓存 DOM**（同一张图可能在一页里出现多次）
- 只用于 content.js 里 `fig`/`solf`/`sol`/`dtab`/`q` 的 `fig` 字段
- 配色跟随 CSS 变量：主线 `#1F3A5F`、强调 `#B8552F`、辅助 `#8A857C`

## 铁律

1. **内容只能来自学案**：不新增情境、分析、小结。要留讲授空间就用 `board` 块或学案原有填空。
2. `tag` 开头中文数字与目录 `toc` 键一一对应，**改 tag 格式 = 目录全废**（见 pitfalls.md 第 1 节）。
3. 每页内容不要溢出：排完跑 `verify.js`，`contentOverflow` 必须为空数组。
