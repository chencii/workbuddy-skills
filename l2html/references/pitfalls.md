# 踩坑记录（改渲染器/写内容前必读）

## 1. 目录链接全跳同一页（2026-10-20 实测踩坑）

`render.js` 的 `coverHTML()` 靠「页 tag 开头的中文数字」建目录→页码映射。
两个错误叠加曾导致 9 条目录全部跳到第 2 页：

- **正则必须匹配真实 tag 格式**。tag 长这样：`'一 · 学习目标'`。
  曾写成 `/环节([一二三四五六七])/`（技能模板迁移时带过来的），永远匹配不上，
  `tagMap` 为空，全部走兜底跳转。
  正确：`/^\s*([一二三四五六七八九十]+)\s*[·、.]/`。
- **索引是 0 基**。`jump(i)` 的 `i` 就是 `.slide` 下标，而 `PAGES[0]` 就是封面，
  所以存 `i` 不要存 `i + 1`。
  （q2html 模板里 `slides.length + 1` 之所以对，是因为它的 slides 数组**不含封面**；
  跨模板抄算法前先核对索引基准。）
- 兜底用 `jump(0)`（回封面），不要用 `jump(1)`。

**回归测试**：`node scripts/toc_check.js <html>` 会逐条点目录链接，
校验落地页 tag 是否以条目数字开头，顺带测「回到首页」按钮。改渲染器必跑。

## 3. 内容红线：只排版，不增添

用户（教师）反复强调：**严格按照学案文件设计，不出现学案之外的内容**
——不自拟情境、不加分析、不代写小结。学案里的填空、思考题原样保留。
需要讲授空间时用 `board` 块（板书演算空白区）。

## 4. 打印/导出的机制

- `#tPrint` 点击 → `window.__preparePrint()` 临时注入一份「屏幕同款」打印样式
  （逐页精确纸张尺寸 + `print-color-adjust:exact`），`window.print()` 后
  `afterprint` 里 cleanup。**自检 `verify.js` 就是调 `__preparePrint` 看规则数和残留。**
- 手按 Cmd+P 走 CSS 里那份兜底 `@media print`（A4 重排），两套互不干扰。
- `pdftest.js <html> <out.pdf>` 可在无头浏览器里直接产 PDF 做冒烟。

## 5. 题答分离与「下方卡死」（2026-10-20 用户二轮反馈）

用户原话：「跟踪训练 1 解与题型二怎么放在一页了？这显然不合理，题和答案要在一页」
「下方不要卡这么死，要留位置」「好好模仿 q2HTML」。

两种错误版式，都不许再犯：

- **题答分离**：例题排一页、解答排下一页。正确做法是解答用折叠 `ans` 块
  与题目同页（q2html 的答案折叠模式），老师点击展开，学生不提前看到。
- **混页**：把上一题的解答和下一题型的开头内容塞进同一页凑数。
  分页粒度 = 一个教学单元一页，宁可留白也不混排。
- **排满**：内容死死堆到页面底部、贴着左下/右下工具栏。每页放一个单元即可，
  题页尾部用 `board` 板书位（`min-height:14vh`，证明类可用 `tall` 26vh），
  让页面自然停在 60~80% 高度。

自查方法：`verify.js` 的 `contentOverflow` 必须为空（排满必溢出）；
再抽看截图确认页面下部有空白、有「板书 · 演算」区。

## 6. 字号上限与全屏（2026-10-20 大屏需求）

用户上课用电子白板，要求「字号按屏幕大小动态调整、全班看得清」。

- **`--u` 的上限不能钉死在小屏**。曾为 `clamp(16px,1.9vmin+8px,28px)`——
  4K 白板（vmin=21.6px）本该给到 49px，却被截到 28px，字只有物理尺寸的一小半。
  现为 `clamp(16px,1.9vmin+8px,46px)`：实测 1366×768→22.6px、1920×1080→28.5px、
  3840×2160→46px，且三种视口逐页无溢出（屏幕越大行高和可用高度同比例放大，
  不会挤爆版面）。
- **全屏按钮**（右上角工具栏，`#bFs`，快捷键 F）是字号放大的开关：
  浏览器窗口化时 vmin 只是窗口尺寸，点了全屏 vmin 才变成屏幕尺寸。
  按钮文案/`.on` 状态由 `fullscreenchange` 事件同步，Esc 退出也会同步。
- **≤620px 隐藏全屏按钮**：手机本身即全屏应用，且 iOS 不支持元素全屏。
- 回归测试：`node scripts/fs_font_test.js <html>`——三种视口量字号+查溢出，
  再实际点击/F 键/退出全屏验证状态同步。

## 9. 内容区小字下限（2026-10-22 用户反馈）

用户（教师，上课投电子白板）反馈「定义和图象特点两列字太小，讲解内容字必须足够大」。
整改记录，写内容时直接遵守：

- **讲解性表格别用 `tbl`**：`.tbl` 是三线表样式，字号仅 .78em（曾因此被点名）。
  定义、概念对比这类要念给学生听的内容，用 `def` 定义卡（字号 100%）或 `dt` 行。
  （`.tbl` 字号已从 .78em 提到 .92em 兜底，但首选仍是 def/dt。）
- **`dtab` 只适合放图**：单元格宽约半页（~585px），图内文字按 13.5px 设计会被缩放得更小。
  流程框图要放大字就**全宽竖排**（一页一张图，viewBox ≈1100 宽、图内字 20px），
  别两张并排——并排等于把字缩小一半。
- **图内文字是「内容」不是装饰**：流程框 ≥20px、坐标图刻度 ≥15.5px、选项字母 ≥20px，
  按显示宽度（不是画布宽度）设计字号；svg 被 max-width 缩小时字会同比例变小。
- 渲染器内容区小字已于 2026-10-22 整体放大一档（ptag .5→.58、def .dlab .48→.58、
  dt .dtl .62→.7、exno .58→.66、abtn .5→.58、qa/exa abody .92→1、封面 toc b .84→.95 等，
  共 29 处，只动 font-size 不动布局）。工具栏/页码等控件字号有 max() 兜底，未动。
  改动方法：`cp render.js /tmp/render.js.bak` → 改 → `diff` 确认只有 font-size 行变化 →
  重渲染 + 三件套 + 拿 `assets/example` 回归一遍。


## 10. 内容缩放滑块 + 橡皮三档（2026-10-22 用户需求）

用户原话：「增加橡皮的功能（放大橡皮能擦掉更大面积）、再增加一个文字放大按钮…
我不喜欢滚轮放大，我要一个按钮，点开之后有一个放大、缩小的滑块」。

### 1. 缩放用 CSS `zoom` 挂在 `.sinner` 上，**不要**挂 `.slide`

- `.slide` 是 `position:fixed;inset:0` 的滚动容器，zoom 它会把滚动容器本身也放大，滚不动。
- 挂 `.sinner` 只放大内容，工具栏/页码/手写 canvas 保持原尺寸（它们都在 `.slide` 之外）。
- 系数走 CSS 变量：`:root{--z:1}`，`.sinner{zoom:var(--z)}`，JS 只改 `--z`（一处生效、易复位）。

### 2. `max-width` 必须写 `min(47em, 100%)`，**不能**写 `calc(100% / var(--z))`

第一版为了「放大后锁在视口内」写成 `min(47em, calc(100% / var(--z)))`，实测 150% 时
内容视觉宽度只有 902px（视口 1440），两侧大片留白——**多除了一次 zoom**。
Chromium 的 zoom 已经让百分比宽度按放大后的可用宽解析，正确写法：

```css
.sinner{width:100%;zoom:var(--z);max-width:min(47em,100%);}
```

实测：z=1 视觉宽 1180（47em 生效）；z=1.5 视觉宽 1354（= 视口内容区宽，充满且不溢出）。

### 3. 手写笔迹必须跟着换算（`window.__inkRescale(ratio)`）

笔迹点存的是「视口坐标 + scrollTop」（放大后的视觉坐标）。改 `--z` 后旧笔迹会漂，
所以 apply 时按 `new/old` 比例缩放所有点并清缓存重绘。近似正确（zoom 会重排换行，
不是严格等比），但视觉上能跟住内容。hw.js 里暴露 `__inkRescale`，deck.js 每次 apply 调它。

### 4. 橡皮：每笔记录自己的 `size`，别在 outline 时读全局

旧代码 `outlineOf` 用 `s.tool==='eraser' ? eraserSize : s.size` —— eraserSize 是全局量，
一旦可调，换档后**所有旧橡皮笔迹会按新尺寸重算**（擦除区域变大/变小，页面全变）。
正确：`beginStroke` 时把当时的尺寸写进 `s.size`，`outlineOf` 一律用 `s.size`。
三档 14/26/44px，点橡皮进模式、再点循环，按钮文案实时显示「橡皮·中」。

### 5. 打印固定按 100% 输出

`preparePrint()` 开头把 `--z` 临时设 1 并 `__inkRescale(1/z)`，cleanup 里恢复
（`__inkRescale(z)`），否则放大状态下导出的 PDF 会版面错乱。打印隐藏列表里要加 `.zoom-panel`。

### 6. 滑块聚焦时方向键被抢

`.slide` 的翻页 keydown 原来不判断焦点，滑块聚焦后按方向键会「边调滑块边翻页」。
deck.js 的 keydown 开头加：`INPUT/TEXTAREA/SELECT/contentEditable` 直接 return。

### 7. 加按钮要重测工具栏遮挡

`.tmr` 里多一颗 `#bZoom`（约 45px）。用「文字 Range 矩形 vs 工具栏矩形」逐页逐视口测
（元素盒子会假阳性：`.runt`/`.sinner>*` 的盒子含右侧留白）。实测 390~1920 共 10 档
无碰撞，200% 缩放也无横向溢出。回归脚本：`scripts/zoom_test.js`（19 项）。
